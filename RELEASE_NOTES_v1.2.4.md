## 📋 Что нового

### 🐛 Исправления багов

#### 1. **AI Signal Manager - Очистка истекших сигналов** (f50b1d4)
**Проблема:**
- Вкладка AI Analysis показывала старые истекшие сигналы (7+ дней назад)
- Сигналы накапливались и не удалялись автоматически
- Метод `_cleanup_expired_signals()` не проверял дату истечения

**Исправление:**
- ✅ Добавлена проверка `is_expired()` в методе очистки
- ✅ Автоочистка запускается при загрузке state
- ✅ Удаляются все истекшие сигналы (>24 часа)

**Результат:**
- Вкладка AI Analysis теперь показывает только актуальные сигналы
- Файл `active_signals.json` автоматически очищается от старых записей

---

#### 2. **AI Scheduler - Исправлен cooldown механизм** (aeafd93)
**Проблема:**
- Scheduler пропускал ВСЕ запланированные времена анализа
- Логи: `Skipping 03:00, 06:00, 09:00... - last run 265s ago`
- `last_run` обновлялся даже когда анализ не запускался
- Cooldown 5 минут блокировал все запуски

**Исправление:**
- ✅ `last_run` обновляется ТОЛЬКО после реального выполнения анализа
- ✅ Добавлен автосброс `last_run` если прошло >1 часа (защита от застревания)
- ✅ Улучшено логирование для диагностики
- ✅ Добавлен флаг `analysis_ran` для проверки выполнения

**Результат:**
- Анализ запускается строго по расписанию
- Cooldown работает корректно (5 минут между запусками)
- Нет застреваний при сбоях

---

#### 3. **Поддержка расписаний с шагом 5 минут** (d71ed81)
**Улучшение:**
- Уменьшен cooldown с 300s до 290s (4.8 минуты)
- Теперь можно ставить расписание: `06:00, 06:05, 06:10, 06:15`
- Защита от двойного запуска сохранена

**Примеры рабочих расписаний:**
```yaml
schedule:
  times:
    - 06:00
    - 06:05
    - 06:10
    - 09:00
    - 09:05
    - 12:00
    - 12:05
    - 12:10
```
