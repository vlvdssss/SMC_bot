# ML Training Data Collection System

## 📁 Структура папки

Эта папка содержит данные для machine learning анализа торговой системы.

### Файлы данных

1. **market_snapshots.csv** (47 колонок)
   - Записывается каждый раз при проверке сигналов
   - Содержит: цена, индикаторы (ATR, EMA, RSI, MACD, Bollinger Bands), свечные паттерны, сессия, волатильность, тренд

2. **ai_decisions.csv** (17 колонок)
   - Записывается когда AI дает сигнал
   - Содержит: рекомендация AI, уровень confidence, entry/sl/tp, reasoning, контекст рынка, сработал ли триггер, была ли исполнена сделка

3. **trade_outcomes.csv** (23 колонок)
   - Записывается когда сделка закрывается
   - Содержит: детали сделки, результат (PnL), длительность, условия рынка при входе, данные AI, причина закрытия

### Файл рекомендаций

**recommendations_YYYYMMDD_HHMMSS.json** - результат еженедельного анализа

## 🚀 Как использовать

### Шаг 1: Сбор данных (автоматический)

Просто запустите бота в обычном режиме:

```bash
python main.py
```

Бот автоматически будет собирать данные в CSV файлы. **Не трогайте бота всю неделю!**

### Шаг 2: Анализ данных (в конце недели)

**В пятницу вечером** (после закрытия торговой недели) запустите анализ:

```bash
python analyze_week.py
```

Или двойным кликом на файл `analyze_week.py`

### Шаг 3: Изучите рекомендации

Откройте файл `recommendations_YYYYMMDD_HHMMSS.json` и изучите:

1. **best_hours** - лучшие часы для торговли (высокий winrate)
2. **avoid_hours** - часы которых лучше избегать (низкий winrate)
3. **best_session** - лучшая торговая сессия (ASIA/EUROPE/US)
4. **optimal_atr** - оптимальный уровень волатильности (ATR)
5. **optimal_rsi** - оптимальный уровень RSI для входа
6. **optimal_trend** - лучший тип тренда для торговли
7. **ai_execution_rate** - процент исполненных AI сигналов

### Шаг 4: Примените рекомендации

На основе анализа вы можете:

1. **Добавить часовые фильтры** в `config/trading.yaml`:
   ```yaml
   trading:
     hours:
       enabled: true
       allowed_hours: [9, 10, 11, 14, 15, 16]  # Лучшие часы из анализа
   ```

2. **Отключить худшие часы** - не торговать в периоды с низким winrate

3. **Настроить сессии** - сфокусироваться на лучшей сессии

4. **Добавить фильтры условий** - торговать только при оптимальных ATR/RSI/Trend

## 🔍 Что анализируется

### 1. Часовой анализ
- Группировка сделок по часам
- Расчет winrate и среднего PnL для каждого часа
- Определение лучших (>55% WR) и худших (<45% WR) часов

### 2. Анализ рыночных условий
- **ATR (волатильность)**: низкая, средняя, высокая, экстремальная
- **RSI (momentum)**: oversold, weak, neutral, strong, overbought
- **Trend**: strong uptrend, uptrend, sideways, downtrend, strong downtrend

### 3. Анализ сессий
- ASIA (02:00-10:00)
- EUROPE (10:00-16:00)
- US (16:00-22:00)

### 4. Качество AI сигналов
- Соотношение BUY/SELL сигналов
- Процент триггеров (сколько сигналов сработало)
- Процент исполнения (сколько сигналов превратилось в сделки)
- Причины пропуска сигналов

## ⚠️ Важные замечания

1. **Минимум данных**: Для качественного анализа нужно минимум 50-100 сделок
2. **Не прерывайте сбор**: Запустите бота и не останавливайте всю неделю
3. **Регулярный анализ**: Проводите анализ каждую неделю для отслеживания изменений
4. **Не удаляйте данные**: CSV файлы накапливают историю - чем больше данных, тем точнее анализ

## 🎯 Цель системы

Система ML анализа помогает **найти оптимальные условия для торговли** на основе РЕАЛЬНЫХ данных вашего бота, а не теоретических предположений.

После нескольких недель сбора данных (500+ сделок) можно будет обучить ML модели для:
- Предсказания вероятности успеха сделки
- Автоматической фильтрации плохих условий
- Оптимизации размера позиции на основе условий рынка
