# BAZA Trading Bot v1.2.4 - КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ AI SIGNAL EXPIRATION 🎯

## 🚨 Критическое обновление

Это **критическое** обновление решает серьёзную проблему с системой истечения AI сигналов, которая приводила к повторному использованию старых сигналов.

---

## 🎯 ГЛАВНОЕ ИСПРАВЛЕНИЕ: Система истечения AI сигналов

### Проблема которая исправлена:
```
❌ Было: 
- Сигнал дан в 11:00 на покупку XAUUSD 4530
- Цена колебалась 4525, так и не дошла до 4530
- Через 1 час сигнал НЕ истекал
- Система продолжала использовать старый сигнал
- При рестарте бота старые сигналы загружались заново

✅ Стало:
- Сигнал дан в 11:00 на покупку XAUUSD 4530
- Цена колебалась 4525, не дошла до 4530
- Через 60 минут сигнал АВТОМАТИЧЕСКИ истекает
- Старый сигнал удаляется и больше не используется
- При рестарте бота старые сигналы НЕ загружаются
```

### Что исправлено:

✅ **Автоматическое истечение сигналов**
- Сигналы корректно истекают через 60 минут (настраивается в `ai.yaml` → `validity_minutes`)
- Больше никаких "бессмертных" сигналов

✅ **Автоматическая очистка файла**
- `data/ai_signals/active_signals.json` всегда содержит только валидные сигналы
- Старые сигналы удаляются при сохранении

✅ **Правильная загрузка при рестарте**
- При запуске бота загружаются только свежие сигналы (< 60 минут)
- Истекшие сигналы фильтруются и удаляются из файла

✅ **Фикс итератора в check_triggers**
- Исправлена критическая ошибка когда удаление внутри цикла ломало итератор
- Теперь все истекшие сигналы гарантированно удаляются

---

## 🐛 Технические детали

### 4 критических бага исправлено:

1. **_save_state()**: Сохранял ВСЕ сигналы, включая `time_expired` и `price_invalidated`
   - **Исправлено**: Сохраняет только `pending` сигналы, не истекшие по времени

2. **_load_state()**: Проверял только 24h (`is_expired()`), игнорировал `validity_minutes`
   - **Исправлено**: Проверяет возраст через `validity_minutes` (60 мин по умолчанию)
   - **Бонус**: Автоматически пересохраняет файл если отфильтровались старые сигналы

3. **check_triggers()**: Удалял `triggered` сигналы ВНУТРИ цикла, ломая итератор
   - **Исправлено**: Собирает и удаляет ПОСЛЕ цикла

4. **check_triggers()**: Сигналы `time_expired` и `price_invalidated` оставались в списке
   - **Исправлено**: Собирает все expired сигналы и удаляет их ПОСЛЕ цикла

## ⚙️ Настройки

Время истечения сигналов настраивается в `config/ai.yaml`:

```yaml
market_analyst:
  signals:
    validity_minutes: 60  # По умолчанию 60 минут
```
