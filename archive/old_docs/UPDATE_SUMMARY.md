## 🎯 Как это работает

### Пользователь:

1. Нажимает `🔄 Проверить обновления`
2. Видит окно с информацией о новой версии
3. Нажимает `Обновить`
4. Наблюдает прогресс-бар (0-100%)
5. Нажимает `Перезапустить`
6. Видит обновленную версию

### Разработчик:

1. Меняет `APP_VERSION` в `version.py`
2. Запускает `python build_exe.py`
3. Создает GitHub Release с EXE
4. Обновляет `version.json` с новым URL
5. Коммитит и пушит `version.json`

✅ Пользователи получают обновление автоматически!

1. **Создать GitHub репозиторий** (если еще нет)
2. **Добавить `version.json` в корень репозитория:**
   ```json
   {
     "latest_version": "1.0.0",
     "download_url": "https://github.com/USER/REPO/releases/download/v1.0.0/BAZA_TradingBot_v1.0.0.exe",
     "size_mb": 206,
     "changelog": [
       "Первый релиз BAZA Trading Bot",
       "AI Market Analysis",
       "Pure AI Trading Mode",
       "Система автоматических обновлений"
     ]
   }
   ```

3. **Обновить `VERSION_CHECK_URL` в `version.py`:**
   ```python
   VERSION_CHECK_URL = "https://raw.githubusercontent.com/YOUR_USER/YOUR_REPO/main/version.json"
   ```

4. **Создать GitHub Release:**
   - Tag: `v1.0.0`
   - Название: `BAZA Trading Bot v1.0.0`
   - Загрузить: `BAZA_TradingBot_v1.0.0.exe`

5. **Протестировать обновление** на чистой системе
