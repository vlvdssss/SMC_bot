### 2. 💰 Фиксированный Стоп-Лосс

**Что изменилось:**
- Внедрен фиксированный риск $10 на лот 0.01
- Для XAUUSD: **100 пипсов = $10 риск**
- GPT больше не выбирает стоп - он всегда фиксированный

**Логика:**
```
Лот 0.01 = $10 риск
Стоп-Лосс: 100 пипсов от входа

Для BUY:
  Entry: $4950
  SL: $4950 - $1.00 = $4949 (100 пипсов)
  
Для SELL:
  Entry: $4950
  SL: $4950 + $1.00 = $4951 (100 пипсов)
```

**Преимущества:**
- ✅ Предсказуемый риск на каждую сделку
- ✅ Легко масштабировать (0.02 лот = $20 риск)
- ✅ Защита от слишком широких стопов
- ✅ Стандартизированный риск-менеджмент

### 3. 🎯 GPT Определяет Take-Profit

**Что изменилось:**
- GPT анализирует рынок и ставит TP на следующий уровень
- Минимальный R:R = 2:1 (200 пипсов)
- Рекомендуемый R:R = 3:1 или выше

**Требования к TP:**
- Должен быть на major resistance/support уровне
- Минимум 200 пипсов от входа ($20 профит на 0.01 лот)
- Рассчитывается на основе структуры рынка

### 4. 🔄 Идеальный Трейлинг Стоп

**Что добавлено:**

#### A) Автоматический Breakeven
```yaml
breakeven:
  enabled: true
  activation_profit_pips: 25  # Активация при +25 пипсах ($2.50)
  offset_pips: 5  # SL на +5 пипсов от входа
```

**Логика:**
1. Когда профит достигает 25 пипсов
2. Автоматически переводим SL на +5 пипсов от входа
3. Гарантированная прибыль даже при откате

#### B) Агрессивный Трейлинг
```yaml
trailing_stop:
  activation_profit_pips: 20  # Активация после $2 профита
  distance_pips: 15  # Держать SL на 15 пипсах от цены
  step_pips: 3  # Обновлять каждые 3 пипса
```

**Как работает:**
1. **Breakeven @ +25 pips** → SL на entry+5 pips (гарантия +$0.50)
2. **Trailing @ +30 pips** → SL начинает двигаться за ценой
3. **Каждые 3 пипса** движения → SL обновляется
4. **Расстояние 15 пипсов** → SL всегда на 15 пипсов от текущей цены

**Пример:**
```
Entry: $4950
Profit +25 pips → SL: $4950.50 (breakeven+5)
Profit +30 pips → SL: $4951.50 (price-15 pips, trailing начался)
Profit +50 pips → SL: $4953.50 (trailing продолжается)
Profit +100 pips → SL: $4958.50 (защита $8.50 прибыли)
```

## 🔧 Как Использовать

### 1. Запуск бота
```powershell
# Активировать venv
.\.venv\Scripts\Activate.ps1

# Запустить бота
python main.py
```

### 2. Мониторинг
- Проверяй логи на наличие анализа:
  ```
  [AI] Analysis completed: BUY (confidence: 85%)
  ```
- Следи за breakeven:
  ```
  [Breakeven] ✅ #12345 XAUUSD BUY: Moved to breakeven
  ```
- Контролируй трейлинг:
  ```
  [TrailingSL] ✅ #12345 XAUUSD BUY: SL moved
  ```

### 3. Настройка (опционально)

**Изменить риск:**
```yaml
# config/trading.yaml
risk:
  default_sl_pips: 100  # $10 на 0.01 лот
```

**Изменить breakeven:**
```yaml
# config/trading.yaml
trailing_stop:
  breakeven:
    activation_profit_pips: 25  # Когда активировать
    offset_pips: 5  # Сколько прибыли защитить
```

**Изменить трейлинг:**
```yaml
# config/trading.yaml
trailing_stop:
  distance_pips: 15  # Расстояние от цены
  step_pips: 3  # Частота обновления
```
