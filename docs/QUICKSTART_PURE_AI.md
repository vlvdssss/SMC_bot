# 🎯 БЫСТРЫЙ СТАРТ: Pure AI Trading Mode

## ЧТО СДЕЛАНО

### ✅ Реализовано
1. **PureAITrader** класс - торговля только по GPT сигналам
2. **GUI Toggle** - переключатель между режимами в интерфейсе
3. **Дедупликация** - проверка дубликатов сигналов (±0.1%)
4. **Интеграция с LiveTrader** - автоматическое исполнение AI сигналов
5. **Логирование** - все действия записываются в логи

### 📋 Параметры
- **Интервал анализа:** каждые 2 часа (00:00, 02:00, 04:00... 22:00)
- **Таймфрейм сделок:** 15 минут
- **Символы:** XAUUSD (золото), EURUSD (доллар)
- **Минимальная уверенность:** 70%
- **Лимит сделок:** 5 в день
- **Cooldown:** 2 часа между сделками одного символа

## КАК ЗАПУСТИТЬ

### 1. Убедись что есть OpenAI API Key

```bash
# В файле .env добавь:
OPENAI_API_KEY=sk-твой-ключ-здесь
```

Или через GUI: **⚙ Настройки** → OpenAI API Key

### 2. Запусти бота

```bash
python main.py
```

### 3. Выбери режим

В интерфейсе найди **"🎯 Режим торговли"**:

- **⚡ Strategy + AI** - стратегия анализирует, GPT фильтрует
- **🤖 Pure AI Trading** - только GPT принимает решения ⬅️ Выбери это!

### 4. Нажми СТАРТ

Бот начнет работать:
- Каждые 2 часа GPT анализирует рынок
- Создаются сигналы с entry/SL/TP
- Автоматически открываются сделки при достижении цены

## ПЕРЕКЛЮЧЕНИЕ РЕЖИМОВ

Можно переключать **БЕЗ остановки бота**:

1. Выбери другой режим в Toggle
2. Бот автоматически переключится
3. Логи покажут: `[MODE] Переключено на: ...`

### Strategy + AI → Pure AI
```
1. Останавливается стратегия
2. Запускается PureAITrader
3. Начинается 2-часовой цикл
```

### Pure AI → Strategy + AI
```
1. Останавливается PureAITrader
2. Активируется стратегия
3. GPT работает как фильтр
```

## НАСТРОЙКА (опционально)

Открой `src/ai/pure_ai_trader.py` и измени:

```python
class PureAITrader:
    ANALYSIS_INTERVAL = 2 * 60 * 60    # 2 часа → можно изменить на 3 или 4
    MIN_CONFIDENCE = 70                 # 70% → можно повысить до 75-80
    MAX_TRADES_PER_DAY = 5              # 5 сделок → можно снизить до 3
    COOLDOWN_HOURS = 2                  # 2 часа → можно увеличить до 4
```

Перезапусти бота после изменений.

## ПРОБЛЕМЫ?

### Pure AI не запускается

**Решение:**
1. Проверь `.env`: есть ли `OPENAI_API_KEY`?
2. Перезапусти: `python main.py`
3. Смотри логи: ищи `[ERROR]`

### Сигналы не создаются

**Причины:**
- Confidence < 70% (GPT не уверен)
- Дубликат (похожий сигнал уже есть)
- Лимит 5 сделок достигнут
- Cooldown 2 часа активен

**Решение:** дождись следующего цикла (2 часа)

### Дорого на GPT

**Решение:**
1. Увеличь интервал: 3-4 часа
2. Используй только XAUUSD
3. Ограничь сделки: 3 в день
