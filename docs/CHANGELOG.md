## [v4.0] - 2026-02-02

### 🚀 Новые возможности
- **Автоматический установщик** - упрощённая установка для новых пользователей
  - `install.ps1` - полный установщик с проверками и диагностикой
    - Проверка версии Python (требуется 3.9+)
    - Интерактивное пересоздание venv при проблемах
    - Автоматическая настройка политики выполнения PowerShell
    - Проверка всех критических пакетов (MetaTrader5, pandas, OpenAI и др.)
    - Проверка конфигурационных файлов
    - Создание необходимых директорий
    - Подробный отчёт о результатах установки
  - `quick_install.ps1` - быстрая установка одной командой
    - Минимальная диагностика
    - Тихий режим установки (--quiet)
    - Опция `--clean` для пересоздания окружения
    - Оптимизирован для скорости (~2-3 минуты)
  - `install.bat` - wrapper для двойного клика
    - Автоматический обход политики выполнения
    - Удобно для неопытных пользователей
  - `check_install.ps1` - скрипт проверки установки
    - Проверка Python и venv
    - Проверка всех критических пакетов
    - Проверка конфигурационных файлов
    - Проверка структуры директорий
    - Цветной вывод с рекомендациями
  - **Документация:**
    - `INSTALL_GUIDE.md` - подробная инструкция для пользователей
    - `TROUBLESHOOTING.md` - решение типичных проблем (15+ сценариев)
    - `QUICK_START.md` - шпаргалка быстрого старта (5 минут)
    - `docs/INSTALLATION_FILES.md` - описание всех установочных файлов

### ✅ Исправления
- **Расчет PnL для XAUUSD** - исправлена формула `estimated_profit` в live_trader.py
  - Старая: `price_diff * volume * 100` (двойное умножение contract_size)
  - Новая: `price_diff * volume * contract_size` (contract_size=100)
  - Скрипт `fix_pnl.py` для исправления исторических данных
  
- **Кнопка Delete Signal** - полная интеграция удаления сигналов
  - Добавлена инициализация SignalManager в BotManager
  - Кнопка удаления в GUI с визуальной обратной связью
  - Telegram callback handler вызывает cancel_signal() перед удалением сообщения
  - Уведомления в Telegram при удалении

- **Дублирование GPT запросов** - защита от повторных вызовов
  - Добавлен MIN_INTERVAL_SECONDS (60 сек) в analyst_scheduler.py
  - Отслеживание _last_analysis_time для каждого символа
  - Логирование предупреждений при попытке дублирования

### ⚙️ Конфигурация
- **AI Settings** - увеличен min_confidence до 75% (с 70%)
- **Trading Settings** - оптимизация параметров риск-менеджмента
- **Portfolio** - адаптивный lot_multiplier (0.5x - 1.5x)

### 🎨 Улучшения UX
