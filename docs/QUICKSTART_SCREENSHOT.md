# 🚀 Быстрый старт: AI Analyst со скриншотами

## 📸 Как использовать новую функцию за 3 шага

### ⚡ Шаг 1: Настройка (один раз)

1. Убедись что в `.env` есть:
   ```
   OPENAI_API_KEY=your_api_key_here
   ```

2. У тебя должен быть доступ к GPT-4o (Vision)
   - Проверь на [platform.openai.com](https://platform.openai.com)
   - Баланс должен быть > $0

---

### 🎯 Шаг 2: Сделать скриншот MT5

**Вариант А: PrintScreen**
1. Открой график в MT5
2. Нажми `PrintScreen` на клавиатуре
3. Открой Paint / любой редактор
4. Ctrl+V и сохрани как PNG/JPG

**Вариант Б: MT5 встроенный**
1. Открой график в MT5
2. Нажми `F12` (встроенный скриншот MT5)
3. Файл сохранится в папку MT5

**Вариант В: Snipping Tool**
1. Win+Shift+S (Windows 10/11)
2. Выдели область графика
3. Сохрани из буфера обмена

---

### 💬 Шаг 3: Отправить AI аналитику

1. Запусти BAZA: `python main.py`
2. Нажми **"💬 Чат с аналитиком"**
3. Нажми **"📸 Attach Screenshot"**
4. Выбери сохраненный скриншот
5. (Опционально) Напиши вопрос
6. Нажми **"Send"**
7. Жди анализ (5-10 секунд)

---

## ✅ Что AI умеет анализировать

### Базовый анализ:
- ✅ Тренды (бычий/медвежий/боковой)
- ✅ Уровни (поддержка/сопротивление)
- ✅ Паттерны (голова-плечи, двойное дно, флаги)
- ✅ Точки входа/выхода
- ✅ Оценка риска

### Продвинутый (если видно на графике):
- ✅ Индикаторы (MA, RSI, MACD, BB)
- ✅ Фибоначчи уровни
- ✅ Свечные паттерны
- ✅ Объемы (если включены)
- ✅ SMC концепты (OB, FVG, BOS)

## 🐛 Частые проблемы

### "AI недоступен"
**Причина:** Нет API ключа или закончился баланс
**Решение:**
```bash
# 1. Проверь .env файл
cat .env | grep OPENAI_API_KEY

# 2. Проверь баланс на platform.openai.com
```

### "Failed to load image"
**Причина:** Неподдерживаемый формат или большой размер
**Решение:**
- Используй PNG или JPG
- Уменьши размер до < 5MB
- Проверь права доступа к файлу

### AI не видит детали
**Причина:** Низкое качество или маленький размер
**Решение:**
- Увеличь график в MT5 перед скриншотом
- Используй контрастную тему (темная работает лучше)
- Удали лишние индикаторы для чистоты

### Медленный ответ (10+ секунд)
**Причина:** GPT-4o Vision медленнее обычного
**Решение:**
- Это нормально, подожди
- Уменьши размер изображения
- Не отправляй повторно, пока не получил ответ

## 🎓 Pro Tips

### Для лучших результатов:
1. **Чистый график** - убери лишнее
2. **Контекст** - покажи историю (не только последние 10 свечей)
3. **Конкретика** - задавай точные вопросы
4. **Проверяй** - AI помощник, но не оракул
5. **Комбинируй** - используй с другими инструментами BAZA

### Типичный workflow:
```
1. Анализ графика вручную
2. Формирование торговой идеи
3. Скриншот графика
4. Отправка AI для подтверждения
5. Корректировка плана на основе AI
6. Открытие сделки через "Ручная торговля"
```
