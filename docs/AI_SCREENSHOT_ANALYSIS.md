# 📸 AI Analyst - Screenshot Analysis Feature

## 🎯 Новая функция: Анализ скриншотов графиков MT5

**Дата добавления:** 2 января 2026

---

## ✨ Что добавлено

### 1. **Кнопка загрузки скриншота**
В окне "AI Analyst Chat" добавлена кнопка **"📸 Attach Screenshot"**

### 2. **Автоматический анализ через GPT-4 Vision**
- Загруженные скриншоты автоматически анализируются GPT-4o (Vision model)
- AI дает детальный технический анализ графика

### 3. **Поддержка форматов**
- ✅ PNG
- ✅ JPG/JPEG
- ✅ BMP

---

## 🚀 Как использовать

### Шаг 1: Сделать скриншот в MT5
1. Откройте нужный инструмент в MetaTrader 5
2. Настройте таймфрейм и индикаторы
3. Нажмите **PrintScreen** или используйте MT5 встроенный скриншот (F12)
4. Сохраните изображение

### Шаг 2: Загрузить скриншот в AI чат
1. Откройте **"💬 Чат с аналитиком"** в BAZA
2. Нажмите **"📸 Attach Screenshot"**
3. Выберите сохраненный скриншот
4. (Опционально) Напишите вопрос, например:
   - "Какой тренд на этом графике?"
   - "Где лучшая точка входа?"
   - "Какие уровни поддержки/сопротивления?"
5. Нажмите **"Send"**

### Шаг 3: Получить анализ
AI проанализирует график и предоставит:
- 📈 **Направление тренда** (бычий/медвежий/боковой)
- 🎯 **Ключевые уровни** (поддержка/сопротивление)
- 📊 **Паттерны** (голова-плечи, флаги, треугольники и т.д.)
- 🔵 **Точки входа/выхода** (рекомендации)
- ⚠️ **Оценка риска** (высокий/средний/низкий)

## 🔧 Технические детали

### Реализация
- **Файл:** [src/gui/app.py](../src/gui/app.py)
- **Функция:** `open_ai_chat()` + `attach_screenshot()`
- **API:** OpenAI GPT-4o (Vision)
- **Кодирование:** Base64

### Процесс обработки
1. Пользователь выбирает файл
2. Изображение кодируется в base64
3. Отправляется в GPT-4o Vision API
4. AI анализирует визуальные элементы графика
5. Возвращает структурированный анализ на русском языке

### System Prompt для Vision
```python
"You are an expert trading analyst. Analyze MT5 chart screenshots and provide 
detailed technical analysis including: trend direction, key support/resistance 
levels, chart patterns, entry/exit points, and risk assessment. Answer in Russian."
```

## 💰 Стоимость

### GPT-4o Vision API
- **Модель:** gpt-4o (с vision support)
- **Стоимость:** ~$0.01-0.03 за запрос (зависит от размера изображения)
- **Рекомендация:** Оптимизируйте размер скриншота (не более 2MB)

### Оптимизация
- Используйте скриншоты разумного размера (1920x1080 достаточно)
- Избегайте повторных отправок одного и того же графика
- Формулируйте конкретные вопросы для более точных ответов

### Требования
1. **OpenAI API Key** должен быть настроен в `.env`:

### Данные
- ✅ Скриншоты НЕ сохраняются на сервере
- ✅ Base64 изображение очищается после отправки

AI может определить:
- **Тренды:** восходящий, нисходящий, боковой

## 🐛 Troubleshooting

### Проблема: "AI недоступен"
**Решение:**
- Проверьте OPENAI_API_KEY в .env
- Убедитесь что ключ действителен
- Проверьте баланс OpenAI аккаунта

### Проблема: "Failed to load image"
**Решение:**
- Проверьте формат файла (PNG, JPG, BMP)
- Уменьшите размер изображения (< 5MB)
- Проверьте права доступа к файлу

### Проблема: AI не видит детали графика
**Решение:**
- Увеличьте разрешение скриншота
- Используйте более контрастную цветовую схему
- Сделайте график крупнее перед скриншотом

### Проблема: Медленный ответ
**Причина:** GPT-4o Vision медленнее обычного GPT
**Решение:**
- Уменьшите размер изображения
- Подождите 5-10 секунд (это нормально)
