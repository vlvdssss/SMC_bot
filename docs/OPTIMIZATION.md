# Backtest & Optimization - Документация

## Обзор

В BAZA добавлена новая секция **"BACKTEST & OPTIMIZATION"** для:
1. 📊 Быстрого запуска бэктестов прямо из GUI
2. 🔍 Автоматической оптимизации параметров стратегий

## Где найти

В главном окне программы:
- Прокрутите вниз после секции "MANUAL TRADING"
- Нажмите **▶ BACKTEST & OPTIMIZATION** для раскрытия
- Секция разделена на две колонки: Backtest (слева) и Optimization (справа)

## 📊 Backtest (Левая колонка)

### Описание
Быстрый бэктест стратегии на исторических данных.

### Параметры:
- **Symbol**: XAUUSD, EURUSD или Portfolio
- **Year**: 2023, 2024, 2025

### Как использовать:
1. Выберите символ и год
2. Нажмите **▶ Run Backtest**
3. Дождитесь результатов (5-30 секунд)

## 🔍 Optimization (Правая колонка)

### Описание
Автоматический поиск лучших параметров стратегии через:
- **Grid Search**: полный перебор комбинаций (медленнее, точнее)
- **Random Search**: случайный поиск (быстрее, менее точно)

### Параметры:
- **Method**: Grid Search или Random Search
- **Metric**: метрика для оптимизации
  - `combined` - комбинированная (Sharpe × WinRate × (1-DD))
  - `sharpe` - Sharpe Ratio
  - `profit` - Total Return
  - `winrate` - Win Rate
- **Iterations**: количество итераций (для Random Search)

### Как использовать:
1. Выберите символ и год (используются те же, что в Backtest)
2. Выберите метод оптимизации
3. Выберите метрику
4. Нажмите **🔍 Run Optimization**
5. Наблюдайте прогресс в progress bar
6. Дождитесь результатов (1-10 минут)

## Оптимизируемые параметры

### XAUUSD Strategy:
- `atr_period`: период ATR (14, 20, 30)
- `atr_multiplier`: множитель ATR для SL/TP (1.5, 2.0, 2.5, 3.0)
- `risk_percent`: риск на сделку (1%, 1.5%, 2%)
- `min_rr`: минимальный Risk/Reward (1.5, 2.0, 2.5)
- `ob_lookback`: период для Order Blocks (10, 15, 20)
- `fvg_min_size`: минимальный размер FVG (0.5, 1.0, 1.5)
- `trend_ema_fast`: быстрая EMA (20, 50)
- `trend_ema_slow`: медленная EMA (100, 200)

### EURUSD Strategy:
- `atr_period`: период ATR (14, 20, 30)
- `atr_multiplier`: множитель ATR (1.5, 2.0, 2.5)
- `risk_percent`: риск на сделку (1%, 1.5%, 2%)
- `min_rr`: минимальный Risk/Reward (1.5, 2.0, 2.5)
- `ob_lookback`: период для Order Blocks (10, 15, 20)
- `fvg_threshold`: порог для FVG (0.5, 1.0, 1.5)

## Метрики для оптимизации

### Combined (рекомендуется)
Комбинированная метрика:
```python
Score = Sharpe × (WinRate/100) × (1 - MaxDD/100)
```

**Преимущества:**
- Учитывает прибыльность (Sharpe)
- Учитывает стабильность (WinRate)
- Учитывает риск (MaxDD)
- Баланс между всеми показателями

### Sharpe Ratio
Соотношение доходности к риску.

**Когда использовать:**
- Нужна максимальная эффективность
- Готовы к более высокому риску

### Profit (Total Return)
Чистая прибыльность.

**Когда использовать:**
- Главная цель - максимум прибыли
- Риск не важен

### WinRate
Процент прибыльных сделок.

**Когда использовать:**
- Нужна высокая стабильность
- Психологический комфорт важнее прибыли

## Grid Search vs Random Search

### Grid Search

**Преимущества:**
- Проверяет все комбинации
- Гарантированно найдет лучшую в пространстве
- Детерминированный результат

**Недостатки:**
- Медленный (экспоненциальный рост)
- Для 8 параметров × 3 значения = 6561 комбинация

**Когда использовать:**
- Маленькое пространство параметров
- Нужна максимальная точность
- Есть время (5-10+ минут)

### Random Search

**Преимущества:**
- Быстрый
- Хорошо исследует пространство
- Можно контролировать время (iterations)

**Недостатки:**
- Может пропустить лучшую конфигурацию
- Результат недетерминированный

**Когда использовать:**
- Большое пространство параметров
- Нужен быстрый результат
- Предварительное исследование

## Устранение неполадок

### "Нет данных для бэктеста"

**Проблема:** Файл с данными не найден

**Решение:**
- Убедитесь, что файл `data/backtest/{SYMBOL}_H1_2023_2025.csv` существует
- Запустите `python main.py --download-data` для загрузки

### "Оптимизация портфолио не поддерживается"

**Проблема:** Portfolio optimization требует специальной логики

**Решение:**
- Используйте XAUUSD или EURUSD отдельно
- Оптимизируйте каждый инструмент индивидуально

### Оптимизация зависла

**Проблема:** Слишком много комбинаций

**Решение:**
- Используйте Random Search вместо Grid Search
- Уменьшите iterations до 50-100
- Проверьте CPU usage

### Результаты хуже базовых

**Проблема:** Овerfitting на тестовых данных

**Решение:**
- Тестируйте на другом периоде (out-of-sample)
- Используйте Walk-Forward optimization (будущее улучшение)
- Не оптимизируйте слишком много параметров

## Следующие шаги

### Планируемые улучшения:

1. **Walk-Forward Optimization**
   - Оптимизация на одном периоде, тест на следующем
   - Избежание overfitting

2. **Multi-objective Optimization**
   - Оптимизация нескольких метрик одновременно
   - Pareto frontier

3. **Bayesian Optimization**
   - Умный поиск (не случайный)
   - Быстрее Grid Search, точнее Random Search

4. **Auto-apply Parameters**
   - Автоматическое применение найденных параметров
   - Без ручного редактирования кода

5. **Optimization History**
   - База данных всех запусков
   - Сравнение результатов по времени
