# Telegram Bot с Кнопками

## Описание

Интерактивный Telegram бот с удобными кнопками вместо команд. Позволяет получать информацию о боте без ввода команд.

## Функции

### 📊 Кнопка "Отчёт"
Показывает текущую статистику торговли:
- 💰 Баланс счета
- 📈 Общая и дневная прибыль
- 📊 Количество сделок (всего и сегодня)
- ✅ Прибыльных сделок
- ❌ Убыточных сделок
- 🎯 Winrate в процентах

### ✅ Кнопка "Статус работы"
Показывает текущее состояние бота:
- 🤖 Статус (работает/остановлен)
- 🔄 Режим работы (Strategy/Pure AI)
- 📊 Количество открытых позиций
- 🎯 Количество сделок сегодня
- ⏰ Время последней активности

## Настройка

### 1. Установка зависимостей
```bash
pip install python-telegram-bot
```

### 2. Конфигурация

В `config/telegram.yaml`:

```yaml
telegram:
  enabled: true  # Включить Telegram уведомления
  bot_token: "YOUR_BOT_TOKEN"  # Токен от @BotFather
  chat_id: "YOUR_CHAT_ID"  # ID чата от @userinfobot
  enable_bot: true  # Включить интерактивного бота с кнопками
  
  notify:
    startup: true
    shutdown: true
    trade_opened: true
    trade_closed: true
    daily_report: true
    alerts: true
    
  alert_min_level: "WARNING"
```

### 3. Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например, "BAZA Trading Bot")
   - Введите username бота (должен заканчиваться на "bot", например, "baza_trading_bot")
4. Скопируйте токен (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)
5. Вставьте токен в `config/telegram.yaml`

### 4. Получение Chat ID

1. Откройте Telegram и найдите [@userinfobot](https://t.me/userinfobot)
2. Отправьте команду `/start`
3. Бот пришлет ваш Chat ID (число)
4. Скопируйте Chat ID и вставьте в `config/telegram.yaml`

## Использование

### Запуск бота

Бот запускается автоматически при старте BAZA Trading Bot, если в конфигурации `enable_bot: true`.

### Команда /start

При первом запуске отправьте команду `/start` вашему боту в Telegram. После этого появятся кнопки меню:

```
┌─────────────────────────────┐
│  📊 Отчёт  │  ✅ Статус работы │
└─────────────────────────────┘
```

### Работа с кнопками

Просто нажимайте на кнопки, чтобы получить информацию:

- **📊 Отчёт** - получить полную статистику по торговле
- **✅ Статус работы** - проверить работает ли бот

Бот отвечает мгновенно, читая данные из файла `data/bot_stats.json`.

## Интеграция с системой

### Автоматическое обновление данных

`BotManager` автоматически обновляет файл статистики:
- При запуске бота
- При остановке бота
- При изменении статистики
- При обновлении из MT5

### Отключение автоматических отчетов

Если вам не нужны автоматические уведомления (открытие/закрытие сделок, дневные отчеты), но вы хотите использовать интерактивные кнопки, настройте `telegram.yaml`:

```yaml
telegram:
  enabled: true
  bot_token: "YOUR_TOKEN"
  chat_id: "YOUR_CHAT_ID"
  enable_bot: true  # Бот с кнопками включен
  
  notify:
    startup: false      # Отключить уведомление о запуске
    shutdown: false     # Отключить уведомление об остановке
    trade_opened: false # Отключить уведомления о сделках
    trade_closed: false
    daily_report: false # Отключить дневные отчеты
    alerts: true        # Оставить только критичные алерты
```

Теперь бот не будет "надоедать" уведомлениями, но вы сможете запросить информацию через кнопки когда захотите!

## Troubleshooting

### Бот не отвечает

1. Проверьте что токен правильный в `config/telegram.yaml`
2. Убедитесь что отправили `/start` боту
3. Проверьте логи: `logs/trading.log`

### Неверные данные

Если данные в отчетах неактуальные:
1. Проверьте файл `data/bot_stats.json`
2. Перезапустите бота
3. Убедитесь что MT5 подключен

### Кнопки не появляются

1. Отправьте `/start` снова
2. Проверьте что `enable_bot: true` в конфигурации
3. Убедитесь что библиотека `python-telegram-bot` установлена

## Технические детали

- **Библиотека**: python-telegram-bot >= 21.0
- **Метод**: Long Polling (asyncio)
- **Поток**: Отдельный daemon thread
- **Клавиатура**: ReplyKeyboardMarkup (постоянная)
- **Формат**: HTML разметка

## Безопасность

⚠️ **Важно**:
- Никогда не публикуйте `bot_token` и `chat_id`
- Добавьте `telegram.yaml` в `.gitignore`
- Используйте только личный Chat ID (бот будет отвечать только вам)

## Расширение функционала

Вы можете добавить свои кнопки в `src/monitoring/telegram_bot.py`:

```python
# Добавьте в клавиатуру
self.keyboard = [
    [KeyboardButton("📊 Отчёт"), KeyboardButton("✅ Статус работы")],
    [KeyboardButton("🎯 Новая кнопка")],  # Ваша кнопка
]

# Добавьте обработчик
async def handle_message(self, update, context):
    text = update.message.text
    
    if text == "🎯 Новая кнопка":
        await self.your_custom_handler(update)
```
