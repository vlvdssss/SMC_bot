## 🎓 Умные функции

### 1. **Определение инструмента**
AI автоматически фильтрует новости:
- XAUUSD → показывает USD события
- EURUSD → показывает USD + EUR события
- Общий чат → показывает все важные события

### 2. **Ключевые слова**
Новости добавляются когда пользователь спрашивает:
- "какие новости"
- "что происходит сегодня"
- "экономические события"
- "календарь"
- "что сегодня"

### 3. **Анализ скриншотов**
При загрузке скриншота новости **всегда** добавляются в контекст:
```python
AI System Prompt:
"Today is 02.01.2026, 15:30 UTC. 
Consider these economic events in your chart analysis:
- CPI data at 13:30 UTC (HIGH impact)
- ..."
```

## 🛠️ Технические детали

### Fallback система
Если не удается получить реальные новости из API:
1. Используются **типичные события по дням недели**
2. Понедельник → Retail Sales
3. Вторник → CPI
4. Среда → FOMC (середина месяца)
5. Четверг → Unemployment Claims + ECB
6. Пятница → NFP (первая пятница месяца)

### Кэширование
- Новости обновляются **раз в час**
- Кэш хранится в памяти
- При перезапуске приложения - свежие данные

### Время
- Все время в **UTC**
- Автоматическое преобразование
- Показывается в понятном формате
