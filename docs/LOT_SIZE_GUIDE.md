# 📊 Руководство по Размеру Позиции (Лот)

## 🎯 Что такое Лот?

**Лот** - это единица измерения объёма позиции в трейдинге. Размер лота определяет **сколько денег** вы рискуете в сделке.

## ⚠️ Рекомендации по безопасности

### 🟢 Безопасные размеры (для новичков)

- **Баланс $1,000 - $5,000**: Используйте **0.01 - 0.05 лота**
- **Баланс $5,000 - $10,000**: Используйте **0.05 - 0.10 лота**
- **Баланс $10,000+**: Используйте **0.10 - 0.50 лота**

### 🟡 Средний риск

- **Баланс $10,000+**: Можно использовать **0.50 - 1.00 лота**
- Только для опытных трейдеров
- При уверенности в сигнале

### 🔴 Высокий риск (НЕ РЕКОМЕНДУЕТСЯ)

- **Лот > 1.0**: Только для профессионалов
- Может привести к полной потере депозита
- Используйте только если знаете что делаете

## 🧮 Формула расчёта размера позиции

```
Размер лота = (Баланс × Risk %) / (SL в пипах × Стоимость пипа)
```

### Пример:

- **Баланс**: $10,000
- **Risk per trade**: 1% (то есть $100)
- **Stop Loss**: 50 пипов
- **Инструмент**: EURUSD (стоимость пипа для 0.01 лота = $0.10)

```
Размер лота = ($10,000 × 1%) / (50 пипов × $0.10)
            = $100 / $5
            = 0.20 лота
```

**НО**: Если `max_lot_size = 0.10`, бот ограничит позицию до **0.10 лота** (безопаснее!)

## ⚙️ Настройка в BAZA Trading Bot

### Шаг 1: Откройте Settings

Нажмите кнопку **⚙ Settings** в главном окне

### Шаг 2: Найдите Risk Management

Прокрутите до раздела **💰 Risk Management**

### Шаг 3: Установите параметры

1. **💵 Риск на сделку (% от баланса)**
   - Рекомендация: `1.0` (1%)
   - Максимум: `2.0` (2%)
   - Пример: При балансе $10,000 и риске 1% = максимум $100 на сделку

2. **📊 Максимальный лот (объём позиции)**
   - Новичкам: `0.01 - 0.05`
   - Средний опыт: `0.05 - 0.10`
   - Опытные: `0.10 - 0.50`
   - Профи: `0.50 - 1.00`

### Шаг 4: Сохраните настройки

Нажмите **💾 Save Settings** внизу окна

### Агрессивная стратегия (опытные)

## 💡 Важные советы

1. **Никогда не рискуйте более 2% на сделку** - это золотое правило риск-менеджмента
2. **Начинайте с минимальных лотов** (0.01) и постепенно увеличивайте по мере опыта
3. **Учитывайте волатильность** - золото (XAUUSD) более волатильно чем EURUSD
4. **Проверяйте маржу** - убедитесь что у вас достаточно средств для открытия позиции
5. **Используйте AI Signal TTL** - ограничивайте время жизни сигналов (15-60 минут)

## 🆘 Частые ошибки

### ❌ Ошибка 1: Слишком большой лот для баланса

**Проблема**: Лот 1.0 при балансе $1,000  
**Решение**: Используйте 0.01 лота

### ❌ Ошибка 2: Игнорирование max_lot_size

**Проблема**: Бот не открывает сделки из-за превышения лимита  
**Решение**: Увеличьте `max_lot_size` в Settings или уменьшите `Risk per trade`

### ❌ Ошибка 3: Слишком маленький лот

**Проблема**: Лот 0.01 при балансе $100,000  
**Решение**: Можно безопасно использовать 0.10 - 0.50 лота
