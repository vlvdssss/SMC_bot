### 2. Правильные отчеты о закрытии сделок

**Файл:** `src/live/live_trader.py`

**Изменения:**
- Теперь правильно определяется причина закрытия (TP/SL/Trailing/Breakeven)
- Сравнивается цена закрытия с TP и SL
- Используется порог 0.5$ для определения точности попадания

**Логика:**
```python
# Определяем насколько близко к TP/SL закрылась сделка
tp_distance = abs(close_price - tp_price)
sl_distance = abs(close_price - sl_price)

if profit > 1.0:  # Прибыльная сделка
    if tp_distance < 0.5:
        result_reason = "Take Profit"
    else:
        result_reason = "Trailing Stop"
elif profit < -1.0:  # Убыточная сделка
    if sl_distance < 0.5:
        result_reason = "Stop Loss"
```

**Результат:**
- Исправлена проблема где сделка с TP показывалась как "Trailing Stop"
- Исправлено неправильное отображение прибыли (было $7.97, стало $10.43)
