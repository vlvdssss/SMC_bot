# Инструкция по очистке старых сделок

## 🧹 Скрипт очистки: cleanup_old_trades.py

Этот скрипт удаляет все сделки до указанной даты и пересчитывает статистику с учетом текущего баланса из MT5.

### Что делает скрипт:

1. ✅ Удаляет все сделки до указанной даты из `data/trades_history.json`
2. ✅ Получает текущий баланс из MT5
3. ✅ Пересчитывает статистику (профит, успешные/убыточные сделки)
4. ✅ Обновляет `data/bot_stats.json` с правильными данными
5. ✅ Вычисляет начальный баланс (`starting_balance`)

### 📝 Использование:

#### Вариант 1: Очистить сделки до 27 января 2026

```powershell
python scripts/cleanup_old_trades.py
```

#### Вариант 2: Указать свою дату

```powershell
python scripts/cleanup_old_trades.py 2026-01-25
```

### ⚠️ ВАЖНО:

- **Запускайте скрипт когда MT5 подключен** - иначе баланс не обновится
- **Сделайте бэкап** перед запуском:
  ```powershell
  copy data\trades_history.json data\trades_history_backup.json
  copy data\bot_stats.json data\bot_stats_backup.json
  ```
