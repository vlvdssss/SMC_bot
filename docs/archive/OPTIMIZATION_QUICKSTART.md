## 🚀 Как использовать

### 1. Запустить программу

```bash
python main.py
```

### 2. Открыть секцию

Прокрутите вниз до:
```
▶ BACKTEST & OPTIMIZATION
```

Нажмите для раскрытия.

### 3. Запустить бэктест

**Левая колонка (Backtest):**
1. Выберите Symbol: `XAUUSD`
2. Выберите Year: `2024`
3. Нажмите **▶ Run Backtest**
4. Подождите 10-30 секунд
5. Посмотрите результаты

### 4. Запустить оптимизацию

**Правая колонка (Optimization):**
1. Убедитесь, что Symbol и Year выбраны
2. Выберите Method: `Random Search`
3. Выберите Metric: `combined`
4. Установите Iterations: `50`
5. Нажмите **🔍 Run Optimization**
6. Наблюдайте прогресс
7. Через 2-5 минут получите топ-3 конфигурации

## 📈 Методы оптимизации

### Grid Search
- Полный перебор всех комбинаций
- Гарантированно находит лучшую
- Медленный (5-15 минут)
- Использовать когда: нужна максимальная точность

### Random Search
- Случайная выборка N комбинаций
- Быстрый (2-5 минут)
- Хорошо исследует пространство
- Использовать когда: нужен быстрый результат

## 🎯 Метрики

### Combined (рекомендуется)
```
Score = Sharpe × WinRate × (1 - MaxDD)
```
Баланс между прибылью, стабильностью и риском.

### Sharpe Ratio
Максимальная эффективность (доходность/риск).

### Profit
Максимальная прибыль (Total Return).

### WinRate
Максимальная стабильность (процент прибыльных сделок).

## ⚠️ Важно

### Overfitting
Не тестируйте параметры на тех же данных, на которых оптимизировали!

**Правильно:**
- Оптимизация на 2023
- Тест на 2024
- Проверка на 2025

### Реалистичность
Бэктест != реальная торговля. Учитывайте:
- Проскальзывание
- Комиссии
- Изменение рынка
- Психологические факторы
