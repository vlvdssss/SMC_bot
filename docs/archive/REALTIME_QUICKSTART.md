# ⚡ Real-Time Updates - Быстрый старт

## ✅ Что сделано

Реализован **Optional Enhancement #3: WebSocket Real-Time Updates** для BAZA Dashboard.

### Новые возможности

1. **🟢 Живой индикатор статуса** - показывает режим, время и статус автообновления
2. **📈 Анимированные метрики** - дельты изменений с цветными стрелками (↑↓)
3. **⚡ Настраиваемое автообновление** - интервалы 5, 10, 15, 30, 60 секунд
4. **📊 Статистика обновлений** - количество обновлений, время последнего
5. **⏱️ Прогресс-бар** - визуальный обратный отсчет до следующего обновления
6. **🔔 Уведомления о новых торгах** - всплывают при появлении новых сделок
7. **💾 Оптимизированное кэширование** - TTL 5 секунд, минимальная нагрузка
8. **🔄 Ручное обновление** - кнопка для принудительного обновления с очисткой кэша

## 🚀 Как использовать

### 1. Запустить dashboard

```bash
streamlit run dashboard.py
```

Dashboard откроется автоматически в браузере: http://localhost:8502

### 2. Включить автообновление

В боковой панели:

1. Выберите режим **"📈 Live Trading"**
2. В секции **"⚡ Real-Time Updates"**:
   - Выберите **интервал обновления** (рекомендуется 30 сек)
   - ☑️ Включите **"Включить автообновление"**

### 3. Наблюдать в реальном времени

Dashboard начнет автоматически обновляться с выбранным интервалом:

- **Прогресс-бар** показывает время до следующего обновления
- **Метрики** отображают изменения (зеленые/красные стрелки)
- **Уведомления** появляются при новых торгах

## ⚙️ Технические детали

### Кэширование

```python
@st.cache_data(ttl=5)  # Кэш на 5 секунд
def load_cached_stats():
    return json.load(...)
```

Данные кэшируются на 5 секунд, что снижает нагрузку на диск.

### Session State

```python
st.session_state.prev_metrics = {
    'total_trades': 125,
    'total_profit': 1234.56,
    'win_rate': 67.2,
    'balance': 11234.56
}
```

Сохраняет предыдущие значения для вычисления дельт.

### Автообновление

```python
for i in range(refresh_interval):
    progress = (i + 1) / refresh_interval
    progress_bar.progress(progress)
    status_text.text(f"⏱️ Обновление через {remaining} сек")
    time.sleep(1)

st.cache_data.clear()  # Очистить кэш
st.rerun()  # Перезапустить dashboard
```

## 🔧 Устранение неполадок

### Dashboard не обновляется

1. Проверьте, что бот запущен
2. Проверьте файлы `data/bot_stats.json` и `data/trades_history.json`
3. Нажмите "🔄 Обновить сейчас"
4. Перезапустите Streamlit

### Высокая нагрузка CPU

1. Увеличьте интервал до 30-60 сек
2. Закройте лишние вкладки браузера
3. Используйте ручной режим (auto-refresh OFF)

### Метрики без дельт

Подождите 2+ обновления - нужна история для вычисления изменений.
