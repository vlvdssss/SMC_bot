# 📊 ML Система Анализа - Быстрый Старт

## Что было сделано

✅ **Система автоматического сбора данных**
- MLDataCollector встроен в бота
- Собирает данные в 3 CSV файла (data/ml_training/)
- Работает автоматически в фоне

✅ **Анализатор торговой недели**
- WeeklyAnalyzer анализирует собранные данные
- Находит лучшие часы, условия, сессии
- Выдает JSON с рекомендациями

✅ **Интеграция в бота**
- AI решения логируются автоматически
- Результаты сделок записываются
- Данные накапливаются без вмешательства

## Как пользоваться

### 1. Запусти бота и не трогай до пятницы

```bash
python main.py
```

Бот будет:
- Торговать как обычно
- Автоматически собирать данные в CSV
- Записывать каждое AI решение
- Логировать каждый результат сделки

**НЕ ОСТАНАВЛИВАЙ БОТА!** Пусть работает всю неделю до пятницы вечером.

### 2. В пятницу вечером - запусти анализ

```bash
python analyze_week.py
```

Или просто **двойной клик** на файл `analyze_week.py`

### 3. Изучи результаты

Откроется файл `data/ml_training/recommendations_YYYYMMDD_HHMMSS.json`

Там найдешь:
- **best_hours** - в какие часы винрейт выше 55%
- **avoid_hours** - какие часы лучше не торговать (WR < 45%)
- **best_session** - лучшая сессия (ASIA/EUROPE/US)
- **optimal_atr/rsi/trend** - лучшие условия рынка

### 4. Примени рекомендации

На следующей неделе настрой бота:
- Торгуй только в лучшие часы
- Избегай худшие часы
- Фокусируйся на лучшей сессии

## Что анализируется

1. **Часовой анализ**
   - Группировка по часам (0-23)
   - Winrate и средний PnL для каждого часа
   - Часы с WR > 55% = хорошие
   - Часы с WR < 45% = плохие

2. **Анализ сессий**
   - ASIA (02:00-10:00)
   - EUROPE (10:00-16:00)
   - US (16:00-22:00)
   - Какая сессия приносит больше профита

3. **Рыночные условия**
   - ATR (волатильность)
   - RSI (momentum)
   - Trend (направление)
   - При каких условиях WR выше

4. **Качество AI**
   - Сколько сигналов сработало
   - Сколько сделок открыто
   - Почему сигналы пропускаются

## Собираемые данные

### ai_decisions.csv (17 колонок)
Каждый раз когда AI дает сигнал:
- timestamp, action (BUY/SELL), confidence
- entry/sl/tp prices
- reasoning (почему AI дал сигнал)
- market_context
- triggered (сработал ли), executed (открыта ли сделка)

### trade_outcomes.csv (23 колонок)
Каждый раз когда сделка закрывается:
- trade_id, open/close time, duration
- direction, entry/exit price
- pnl_dollars, pnl_pips, win (True/False)
- session, market conditions
- close_reason

### market_snapshots.csv (47 колонок) 
*Пока базовая версия, полная версия в следующем обновлении*
