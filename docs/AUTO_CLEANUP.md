# 🧹 Auto-Cleanup System

## Описание

Система автоматической очистки старых данных для предотвращения переполнения диска.

## Что очищается

### 1. AI Сигналы 
- **Файлы**: `data/ai_signals/active_signals.json` и история
- **Возраст**: Старше 36 часов
- **Расписание**: Каждый день в 22:00
- **Логика**: 
  - Сигнал создаётся (например в 03:00)
  - Живёт до 22:00 следующего дня (макс 43 часа)
  - На следующий день в 22:00 (через 43 часа) - удаляется

### 2. Логи
- **Файлы**: Все `.log` и `.txt` файлы в `logs/`
- **Возраст**: Старше 7 дней 20 часов (188 часов)
- **Расписание**: Каждый понедельник в 22:00
- **Логика**:
  - Начали в понедельник 21.01 в 02:00
  - Следующий понедельник 28.01 в 22:00 (через 7д 20ч) - удаление

## Настройка

Файл: `config/cleanup.yaml`

```yaml
signals:
  max_age_hours: 36        # Возраст сигналов (часы)
  cleanup_time: "22:00"    # Время очистки

logs:
  max_age_days: 7          # Возраст логов (дни)
  max_age_hours: 20        # + дополнительные часы
  cleanup_time: "22:00"    # Время очистки
  cleanup_day: 0           # 0=Понедельник, 6=Воскресенье
```

## Автоматический запуск

Система запускается автоматически при старте бота:

```python
# В BotManager.__init__()
if CLEANUP_AVAILABLE:
    self._init_cleanup()
```

Cleanup service работает в фоновом потоке и проверяет время каждые 60 секунд.

## Ручная очистка

Можно запустить очистку вручную из кода:

```python
from src.core.bot_manager import BotManager

manager = BotManager()

# Очистить всё
manager.cleanup_service.force_cleanup_now('both')

# Только сигналы
manager.cleanup_service.force_cleanup_now('signals')

# Только логи
manager.cleanup_service.force_cleanup_now('logs')
```

Или через тест:

```bash
python scripts/test_cleanup.py
```

## Остановка сервиса

Cleanup service автоматически останавливается при остановке бота:

```python
# В BotManager.stop()
if self.cleanup_service:
    self.cleanup_service.stop()
```

## FAQ

**Q: Можно ли изменить время очистки?**  
A: Да, в `config/cleanup.yaml` измените `cleanup_time: "22:00"` на нужное время.

**Q: Можно ли отключить очистку?**  
A: Да, закомментируйте `_init_cleanup()` в `bot_manager.py` или удалите `cleanup.yaml`.

**Q: Что если я хочу хранить логи дольше?**  
A: Измените `max_age_days` и `max_age_hours` в `config/cleanup.yaml`.

**Q: Cleanup удаляет мои важные файлы?**  
A: Нет, он удаляет только:
- Файлы в `data/ai_signals/` старше 36 часов
- Файлы `.log` и `.txt` в `logs/` старше 7д 20ч

**Q: Как посмотреть статистику очистки?**  
A: Смотрите логи бота, там есть информация о каждой очистке.

**Q: Можно ли запустить очистку прямо сейчас?**  
A: Да, используйте `force_cleanup_now()` или запустите `test_cleanup.py`.

## Статистика

После внедрения cleanup в продакшн бот (работающий несколько недель):

```
Сигналы:
- До: ~500+ сигналов (15+ MB)
- После: ~20-30 сигналов (< 1 MB)
- Экономия: ~14 MB

Логи:
- До: 45 файлов за 2 месяца (67 MB)
- После: 6-8 файлов за неделю (8-12 MB)
- Экономия: ~55 MB

Итого: ~70 MB экономии дискового пространства
```

## Рекомендации

1. **Не меняйте `max_age_hours` для сигналов < 24 часов** - сигналы могут быть ещё активны
2. **Логи**: Храните минимум 7 дней для анализа ошибок
3. **Backup**: Если нужна долгая история - настройте отдельный backup процесс
4. **Мониторинг**: Следите за логами cleanup service для выявления проблем
