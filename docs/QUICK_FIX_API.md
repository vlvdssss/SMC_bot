# ⚡ БЫСТРОЕ РЕШЕНИЕ: Ошибка GPT API

## 🔴 Проблема обнаружена
Диагностика показала: **Invalid API Key** (ключ неверный)

## ✅ Решение (5 минут)

### Шаг 1: Получи новый API ключ
1. Открой: https://platform.openai.com/api-keys
2. Залогинься в OpenAI аккаунт
3. Нажми **"+ Create new secret key"**
4. Назови его (например: "BAZA_Bot")
5. Скопируй ключ **ПОЛНОСТЬЮ** (начинается с `sk-proj-...`)
   
   ⚠️ **ВАЖНО**: Ключ показывается только один раз! Сразу скопируй!

### Шаг 2: Вставь ключ в конфиг
1. Открой файл: `config/.env`
2. Найди строку:
   ```
   OPENAI_API_KEY=старый_ключ
   ```
3. Замени на новый:
   ```
   OPENAI_API_KEY=sk-proj-твой_новый_ключ_здесь
   ```
4. Сохрани файл (Ctrl+S)

### Шаг 3: Проверь что работает
```bash
python scripts/test_openai_api.py
```

Должно быть:
```
✅ API ключ найден: sk-proj-9aTu...
✅ Формат ключа корректный
✅ Client инициализирован
✅ API соединение работает!
✅ GPT completion работает!
✅ GPT-4o доступен!
✅ ДИАГНОСТИКА ЗАВЕРШЕНА УСПЕШНО!
```

### Шаг 4: Перезапусти бота
1. Закрой бот (если запущен)
2. Запусти снова: `BAZA_TradingBot.exe`
3. В логах должно быть:
   ```
   ✅ [AI] API Key validated: sk-proj-9aTu...
   ✅ [AI] OpenAI client initialized successfully
   ✅ [AI] API connection test successful
   ```
