# Real-Time Dashboard Updates 🔄

## Обзор

Dashboard теперь поддерживает **real-time обновления** с профессиональным UI для мониторинга live торговли.

## Основные возможности

### 1. 🎯 Живой индикатор статуса

В верхней части dashboard отображается:
- **🟢 Live Trading Mode** - текущий режим
- **⏰ HH:MM:SS** - текущее время
- **🔄 Auto-refresh ON/OFF** - статус автообновления

```
🟢 Live Trading Mode | ⏰ 14:32:15 | 🔄 Auto-refresh ON
```

### 2. ⚡ Настройки автообновления

В боковой панели доступны:

**Интервал обновления:**
- 5 секунд (быстрое)
- 10 секунд
- 15 секунд
- **30 секунд** (по умолчанию)
- 60 секунд (медленное)

**Переключатель:**
- ☑️ Включить автообновление

**Кнопка:**
- 🔄 Обновить сейчас (ручное обновление)

### 3. 📊 Статистика обновлений

При включенном автообновлении показывается:
- **Обновлений:** количество выполненных обновлений
- **Последнее:** время с последнего обновления
- **Прогресс-бар:** визуализация до следующего обновления
- **⏱️ Обновление через X сек** - обратный отсчет

Пример:
```
📊 Статистика обновлений
Обновлений: 42
Последнее: 5с назад

[=========>        ] 65%
⏱️ Обновление через 10 сек
```

### 4. 🔔 Уведомления о новых торгах

При появлении новых торгов показывается:
```
✅ 🆕 Новых торгов: 2
```

### 5. 📈 Анимированные метрики

Все метрики теперь показывают **дельту изменений**:

```
Всего торгов    Общая прибыль      Винрейт          Баланс
    125             $1,234.56        67.2%         $11,234.56
    +3              +$52.30          +1.5%         +$52.30
    ↑               ↑                ↑             ↑
```

**Цветовая индикация:**
- 🟢 Зеленая стрелка ↑ - увеличение
- 🔴 Красная стрелка ↓ - уменьшение
- ⚪ Без стрелки - без изменений

### 6. 💾 Кэширование данных

Для плавной работы используется:
- **TTL кэш 5 секунд** - данные обновляются не чаще 5 сек
- **Автоматическая очистка** - при ручном обновлении кэш сбрасывается
- **Session state** - сохраняет историю метрик между обновлениями

## Как использовать

### Быстрый старт

1. Запустите dashboard:
```bash
streamlit run dashboard.py
```

2. Откройте http://localhost:8501

3. Выберите режим "📈 Live Trading"

4. В боковой панели:
   - Выберите интервал обновления (например, 30 сек)
   - ☑️ Включите "Включить автообновление"

5. Dashboard начнет автоматически обновляться!

### Режимы работы

#### 🔄 Режим автообновления

**Когда использовать:**
- Активная торговля
- Мониторинг в реальном времени
- Отслеживание новых торгов

**Преимущества:**
- Не нужно обновлять вручную
- Видны изменения метрик
- Уведомления о новых торгах

```
Sidebar → ⚡ Real-Time Updates → ☑️ Включить автообновление
```

#### ⏸️ Ручной режим

**Когда использовать:**

**Как обновить:**
```

```

## Технические детали

### Архитектура

```python
# Кэширование данных (TTL 5 сек)
@st.cache_data(ttl=5)
def load_cached_stats():
    return json.load(...)

@st.cache_data(ttl=5)
def load_cached_trades():
    return pd.DataFrame(...)

# Session state для отслеживания изменений
st.session_state.prev_metrics = {
    'total_trades': 125,
    'total_profit': 1234.56,
    'win_rate': 67.2,
    'balance': 11234.56
}

# Автообновление с прогресс-баром
for i in range(refresh_interval):
    progress = (i + 1) / refresh_interval
    progress_bar.progress(progress)
    time.sleep(1)
st.rerun()
```

### Оптимизации

1. **Кэширование:**
   - Файлы читаются не чаще 5 сек
   - Reduces disk I/O
   - Ускоряет обновление UI

2. **Дельта метрик:**
   - Сохраняет предыдущие значения в session_state
   - Вычисляет разницу
   - Показывает зеленые/красные стрелки

3. **Ленивая загрузка:**
   - Графики обновляются только в Backtest режиме
   - Live режим - только метрики и таблицы

## Производительность

| Интервал | CPU | Memory | Disk I/O |
|----------|-----|--------|----------|
| 5 сек | ~3% | 150 MB | Средняя |
| 30 сек | ~1% | 120 MB | Низкая |
| 60 сек | <1% | 100 MB | Очень низкая |

### Рекомендации

✅ **DO:**
- Используйте 30-60 сек для долгосрочной торговли
- Отключайте автообновление при анализе данных
- Закрывайте вкладку, если не используете

❌ **DON'T:**
- Не используйте 5 сек постоянно (высокая нагрузка)
- Не открывайте несколько вкладок с автообновлением
- Не запускайте на слабых машинах с 5 сек интервалом

## Устранение неполадок

### Dashboard не обновляется

**Проблема:** Включено автообновление, но данные не меняются

**Решение:**
1. Проверьте, что бот запущен и торгует
2. Проверьте файлы `data/bot_stats.json` и `data/trades_history.json`
3. Нажмите "🔄 Обновить сейчас" для принудительного обновления
4. Перезапустите Streamlit

### Высокая нагрузка CPU

**Проблема:** CPU загружен на 100%

**Решение:**
1. Увеличьте интервал обновления до 30-60 сек
2. Закройте лишние вкладки browser
3. Используйте ручной режим

### Метрики не показывают дельту

**Проблема:** Нет зеленых/красных стрелок

**Решение:**
1. Подождите первое обновление (нужно 2+ обновления)
2. Проверьте session_state: `st.session_state.prev_metrics`
3. Перезапустите dashboard

### "Новых торгов: 0" постоянно

**Проблема:** Не показываются новые торги

**Решение:**
1. Проверьте, что бот выполняет торги
2. Проверьте `data/trades_history.json`
3. Сбросьте session_state: очистить browser cache
4. Перезапустите Streamlit
