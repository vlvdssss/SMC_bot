# 🕐 AI Scheduler - Гайд по настройке расписания

## Как работает планировщик

AI Scheduler автоматически запускает GPT анализ рынка в заданное время. 
Вы можете настроить **любое количество времён** - хоть 1 раз в день, хоть каждую минуту!

## Файл конфигурации

Откройте `config/ai.yaml` и найдите секцию `schedule`:

```yaml
market_analyst:
  schedule:
    enabled: true
    times:
      - 06:00
      - 09:00
      - '11:15'
      - 12:00
      - 15:00
      - 18:00
      - 21:00
```

## Важные правила

### ⚠️ Формат времени
- **С нулём**: `06:00`, `09:15` (без кавычек)
- **С единицей в начале**: `'11:15'`, `'12:00'` (с кавычками!)

```yaml
# ✅ Правильно
times:
  - 06:00      # без кавычек
  - '11:15'    # с кавычками (начинается с 1)
  - '12:00'    # с кавычками
  - 18:00      # без кавычек

# ❌ Неправильно
times:
  - 11:15      # без кавычек - будет ошибка парсинга YAML!
```

### 🛡️ Ограничения безопасности

Scheduler имеет встроенную защиту:

```yaml
safety:
  min_minutes_between_calls: 30  # Минимум 30 минут между анализами
  max_daily_calls: 10           # Максимум 10 анализов в день
  max_monthly_cost: 20.0        # Максимум $20 в месяц на GPT
```

**Даже если вы зададите 100 времён**, scheduler не запустит больше:
- 10 анализов в день (из-за `max_daily_calls`)
- 1 анализ каждые 30 минут (из-за `min_minutes_between_calls`)

### 🌙 Ночной блок

По умолчанию анализ **не запускается** с 22:00 до 02:00:

```yaml
restrictions:
  night_block:
    enabled: true
    start: '22:00'
    end: 02:00
```

Чтобы отключить:
```yaml
restrictions:
  night_block:
    enabled: false
```

### 📅 Выходные

По умолчанию анализ **не запускается** в выходные:

```yaml
restrictions:
  weekend_block:
    enabled: true
    friday_start: '22:00'  # С пятницы 22:00
    monday_end: 02:00      # До понедельника 02:00
```

Чтобы работать в выходные:
```yaml
restrictions:
  weekend_block:
    enabled: false
```

## 🔍 Как проверить что расписание работает

### 1. Запустите бота и проверьте логи при старте:
```

```

### 2. В указанное время увидите:
```

[AI-Scheduler] Starting analysis for XAUUSD (Volatility OK: ATR $7.39)...
[AI] 📤 Sending request to GPT-4o with 2 screenshots...
[AI-Signal] Created: BUY @ 2742.50 (conf: 85%, expires: 12:15)
```

### 3. Если пропущено:
```
[AI-Scheduler] Skipping 11:15 - last run 180s ago  # Защита от частых запусков
[AI-Scheduler] Analysis blocked: Night time block (22:00-02:00)  # Ночной блок
[AI-Scheduler] Analysis skipped: Low volatility (ATR $1.20 < $2.00)  # Низкая волатильность
```

## 📊 Статистика использования GPT

Каждый анализ = примерно:
- **$0.10 - $0.15** за вызов GPT-4o
- **2-3 минуты** на анализ

**Примеры стоимости:**
- 1 раз в день = ~$3-5 / месяц
- 2 раза в день = ~$6-10 / месяц  
- 5 раз в день = ~$15-25 / месяц
- 10 раз в день = ~$30-50 / месяц (превысит лимит `max_monthly_cost: 20`)

## ❓ FAQ

**Q: Можно ли запускать каждую минуту?**  
A: Технически да, но:
- `min_minutes_between_calls: 30` ограничит до 1 раза в 30 минут
- `max_daily_calls: 10` ограничит до 10 раз в день
- Рекомендуется **минимум 30 минут** между анализами

**Q: Почему анализ не запустился в указанное время?**  
A: Проверьте:
1. `ai_enabled: true` в конфиге
2. Не ночной блок (22:00-02:00)
3. Не выходные (Пт 22:00 - Пн 02:00)
4. Не слишком частые запуски (< 30 минут)
5. Достаточная волатильность (ATR > $2 для XAUUSD)
6. Не превышен дневной лимит (10 анализов)

**Q: Как отключить все ограничения?**  
A:
```yaml
schedule:
  enabled: true
  restrictions:
    night_block:
      enabled: false
    weekend_block:
      enabled: false
safety:
  min_minutes_between_calls: 1
  max_daily_calls: 1000
  max_monthly_cost: 1000.0
```

**Q: Нужно ли перезапускать бота после изменения расписания?**  
A: **ДА!** Scheduler читает конфиг только при запуске.
