# 🚀 Быстрая установка BAZA Trading Bot

## Для друга - самый простой способ

### Вариант 1: Автоматическая установка (рекомендуется)

1. **Скачай проект** на компьютер
2. **Открой PowerShell** в папке с проектом (Shift + ПКМ → "Открыть окно PowerShell здесь")
3. **Запусти команду:**
   ```powershell
   .\install.ps1
   ```

Скрипт всё сделает автоматически! ✨

### Вариант 2: Супер-быстрая установка

Если нужно ещё быстрее (одна команда):
```powershell
.\quick_install.ps1
```

### Вариант 3: С очисткой (если были проблемы)

Если раньше были ошибки, удали старое окружение:
```powershell
.\quick_install.ps1 --clean
```

## ❗ Если появляются ошибки

### Ошибка: "Не удается запустить скрипт"

**Решение:**
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Затем снова запусти install.ps1

### Ошибка: "Python не найден"

**Решение:**
1. Скачай Python 3.9+ с https://www.python.org/downloads/
2. При установке **ОБЯЗАТЕЛЬНО** отметь галочку "Add Python to PATH"
3. Перезапусти PowerShell

### Ошибка: "pip не найден" или "venv не найден"

**Решение:**
```powershell
python -m ensurepip --upgrade
```

## 📋 Что нужно сделать после установки

1. **Настроить конфигурацию:**
   - Перейди в папку `config/`
   - Скопируй файлы `*.example` и убери `.example` из названия
   - Заполни свои данные (MT5, Telegram, OpenAI)

2. **Запустить бота:**
   ```powershell
   .\start_bot.ps1
   ```
   
   Или просто:
   ```powershell
   python main.py
   ```

## 🔧 Полезные команды

### Активировать виртуальное окружение вручную:
```powershell
.\.venv\Scripts\Activate.ps1
```

### Установить дополнительный пакет:
```powershell
pip install название_пакета
```

### Обновить все зависимости:
```powershell
pip install -r requirements.txt --upgrade
```

### Проверить установленные пакеты:
```powershell
pip list
```

## 🆘 Частые проблемы

| Проблема | Решение |
|----------|---------|
| "Access denied" при установке | Запусти PowerShell от имени администратора |
| Долгая установка зависимостей | Это нормально, пакеты большие (особенно ML библиотеки) |
| Ошибки с MetaTrader5 | Убедись что MT5 установлен на компьютере |
| Нет интернета при установке | Установщик требует интернет для скачивания пакетов |

📖 **Подробное руководство по решению проблем:** [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## ✅ Проверка установки

### Автоматическая проверка (рекомендуется):
```powershell
.\check_install.ps1
```

Скрипт проверит:
- ✓ Python версию
- ✓ Виртуальное окружение
- ✓ Все критические пакеты
- ✓ Конфигурационные файлы
- ✓ Необходимые директории

### Ручная проверка:

```powershell
# Активируй окружение
.\.venv\Scripts\Activate.ps1

# Проверь Python
python --version

# Проверь основные пакеты
pip show MetaTrader5
pip show pandas
pip show python-telegram-bot
```

Если всё работает - готово! 🎉

## 💡 Советы

- **Используй виртуальное окружение** - это изолирует пакеты проекта
- **Не удаляй папку .venv** - там все установленные библиотеки
- **Обновляй pip** перед установкой: `python -m pip install --upgrade pip`
- **При проблемах пересоздай окружение** - удали `.venv` и запусти установщик снова
