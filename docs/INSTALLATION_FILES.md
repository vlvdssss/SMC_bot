# 📦 Файлы установки - Описание

## Установочные скрипты

### 🔷 install.ps1
**Полный автоматический установщик**

**Что делает:**
- ✅ Проверяет версию Python (требуется 3.9+)
- ✅ Спрашивает о пересоздании venv при проблемах
- ✅ Создаёт виртуальное окружение
- ✅ Настраивает политику выполнения PowerShell
- ✅ Активирует окружение
- ✅ Обновляет pip
- ✅ Устанавливает все зависимости
- ✅ Проверяет установку критических пакетов
- ✅ Проверяет конфигурационные файлы
- ✅ Создаёт необходимые директории
- ✅ Выводит подробный отчёт и рекомендации

**Когда использовать:**
- Первая установка проекта
- После проблем с зависимостями
- Когда нужна диагностика

**Запуск:**
```powershell
.\install.ps1
```

---

### ⚡ quick_install.ps1
**Быстрая установка одной командой**

**Что делает:**
- ✅ Минимальная проверка Python
- ✅ Создаёт/активирует venv
- ✅ Обновляет pip (тихо)
- ✅ Устанавливает зависимости (тихо)
- ✅ Создаёт директории

**Когда использовать:**
- Быстрая переустановка
- Автоматизация (CI/CD)
- Опытные пользователи

**Запуск:**
```powershell
# Обычная установка
.\quick_install.ps1

# С очисткой старого окружения
.\quick_install.ps1 --clean
```

---

### 🔵 install.bat
**Wrapper для запуска install.ps1**

**Что делает:**
- ✅ Проверяет наличие PowerShell
- ✅ Запускает install.ps1 с обходом политики выполнения

**Когда использовать:**
- Двойной клик вместо командной строки
- Для пользователей незнакомых с PowerShell

**Запуск:**
Двойной клик по файлу `install.bat`

---

### ✔️ check_install.ps1
**Проверка корректности установки**

**Что проверяет:**
- ✅ Версия Python
- ✅ Виртуальное окружение
- ✅ Все критические пакеты
- ✅ Конфигурационные файлы
- ✅ Необходимые директории
- ✅ Основные файлы проекта

**Когда использовать:**
- После установки для проверки
- При подозрении на проблемы
- Перед запуском бота

**Запуск:**
```powershell
.\check_install.ps1
```

**Вывод:**
- 🟢 Всё готово → можно запускать бота
- 🟡 Требуется настройка → создай config файлы
- 🔴 Обнаружены проблемы → переустанови

## Рекомендации

### Для новичков:
1. **Двойной клик** на `install.bat`

1. `.\quick_install.ps1 --clean` - переустановка
2. `.\install.ps1` - диагностика

## Порядок использования

### Первая установка:
```powershell
# 1. Установка
.\install.ps1

# 2. Проверка
.\check_install.ps1

# 3. Настройка конфигов
cd config
copy mt5.yaml.example mt5.yaml
copy telegram.yaml.example telegram.yaml
# Отредактируй файлы

# 4. Финальная проверка
.\check_install.ps1

# 5. Запуск
.\start_bot.ps1
```

### Переустановка:
```powershell
# Вариант 1: Быстрая
.\quick_install.ps1 --clean

# Вариант 2: Полная
Remove-Item .venv -Recurse -Force
.\install.ps1
```

### Обновление пакетов:
```powershell
# Активируй venv
.\.venv\Scripts\Activate.ps1

# Обнови пакеты
pip install -r requirements.txt --upgrade

# Проверь
.\check_install.ps1
```

## Типичные сценарии

```powershell
# Самый простой способ
install.bat  # Двойной клик
```

```powershell
pip install -r requirements.txt --upgrade
```

```powershell
# Исправь политику

```

```powershell
.\check_install.ps1  # Должно быть всё ✅
python main.py       # Запуск бота
```

## Требования к системе

- **OS:** Windows 10/11
- **Python:** 3.9 или выше
- **RAM:** 4GB минимум (8GB рекомендуется)
- **Диск:** 2GB свободного места
- **Интернет:** Для установки пакетов
- **MT5:** Установлен и настроен

## Полезные команды

```powershell
# Узнать версию Python
python --version

# Активировать venv
.\.venv\Scripts\Activate.ps1

# Деактивировать venv
deactivate

# Список пакетов
pip list

# Проверка пакета
pip show MetaTrader5

# Переустановка пакета
pip install MetaTrader5 --force-reinstall

# Очистка pip cache
pip cache purge

# Политика выполнения
Get-ExecutionPolicy
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```
