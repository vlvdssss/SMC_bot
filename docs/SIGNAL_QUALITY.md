# Улучшение качества сигналов

## Проблема

Иногда AI сигналы работают "наоборот":
- При сигнале **BUY** цена идет **вниз** ⬇️
- При сигнале **SELL** цена идет **вверх** ⬆️

Это может быть связано с тем, что рынок работает противоположно ожиданиям модели в текущих условиях.

## Решение 1: Инверсия сигналов 🔄

### Настройка

В файле `config/trading.yaml` добавлена секция `signal_quality`:

```yaml
trading:
  signal_quality:
    invert_signals: false  # Инвертировать сигналы (BUY->SELL, SELL->BUY)
    min_confidence: 75     # Минимальная уверенность AI (0-100)
    min_risk_reward: 1.5   # Минимальное соотношение R:R
```

### Как включить инверсию

1. Откройте `config/trading.yaml`
2. Найдите секцию `signal_quality`
3. Измените `invert_signals: false` на `invert_signals: true`
4. Сохраните файл
5. Перезапустите бота

### Что происходит при инверсии

| Исходный сигнал | После инверсии |
|----------------|---------------|
| **BUY** @ 2850 | **SELL** @ 2850 |
| SL: 2840 | SL: 2870 (старый TP) |
| TP: 2870 | TP: 2840 (старый SL) |

**Важно:** Entry price остается тем же, меняются только направление и SL/TP местами!

## Решение 2: Фильтры качества 🎯

### Минимальная уверенность (min_confidence)

- **По умолчанию:** 75%
- **Что делает:** Отклоняет сигналы с уверенностью ниже порога
- **Рекомендация:** 
  - 70-75% → сбалансированный подход
  - 80-85% → осторожный подход (меньше сигналов, но качественнее)
  - 65-70% → агрессивный подход (больше сигналов)

### Минимальное R:R (min_risk_reward)

- **По умолчанию:** 1.5
- **Что делает:** Отклоняет сигналы с плохим соотношением риск/прибыль
- **Рекомендация:**
  - 1.5 → минимальный фильтр
  - 2.0 → хороший фильтр
  - 2.5+ → строгий фильтр (только лучшие сигналы)

**Формула R:R:**
```
R:R = |TP - Entry| / |Entry - SL|

Пример:
Entry: 2850
SL: 2840 (риск $10)
TP: 2870 (прибыль $20)
R:R = 20 / 10 = 2.0 ✅
```

## Стратегия тестирования

### Шаг 1: Анализ текущих результатов

Проверьте последние 10-20 сделок:
- Сколько сигналов BUY закрылись в минус?
- Сколько сигналов SELL закрылись в минус?
- Есть ли явная тенденция?

### Шаг 2: Пробная инверсия

Если видите что **большинство** сигналов работают наоборот:

1. Включите `invert_signals: true`
2. Запустите бота в **тестовом режиме** (малый лот 0.01)
3. Отслеживайте результаты 1-2 дня

### Шаг 3: Тонкая настройка фильтров

После недели работы:

**Если много ложных сигналов:**
```yaml
min_confidence: 80  # ↑ повысить
min_risk_reward: 2.0  # ↑ повысить
```

**Если слишком мало сигналов:**
```yaml
min_confidence: 70  # ↓ понизить
min_risk_reward: 1.5  # ↓ понизить
```

## Логи и мониторинг

### Лог инверсии

При включенной инверсии в логах будет:
```
[AI-Signal] 🔄 Signal INVERTED: BUY->SELL | Entry: 2850.00000 | 
Old SL/TP: 2840.00000/2870.00000 | New SL/TP: 2870.00000/2840.00000
```

### Лог отклонений

При низкой уверенности:
```
[AI-Signal] ❌ Rejected low confidence: 65% < 75%
```

При плохом R:R:
```
[AI-Signal] ❌ Rejected poor R:R: 1.2 < 1.5 (risk: $10.00, reward: $12.00)
```

## Важные замечания

⚠️ **Инверсия это не волшебная кнопка!**
- Работает только если есть стабильная закономерность
- Не поможет если качество сигналов просто низкое
- Нужно тестировать на истории

✅ **Рекомендованный подход:**
1. Сначала повысьте фильтры качества (min_confidence, min_risk_reward)
2. Соберите статистику за неделю
3. Если есть явная инверсия → включите `invert_signals`
4. Продолжайте мониторинг
