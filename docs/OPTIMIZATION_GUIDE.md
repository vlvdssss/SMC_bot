## Что такое оптимизация

**Оптимизация стратегий** - это автоматический поиск наилучших параметров торговой стратегии на исторических данных.

### Зачем нужна оптимизация?
- 📈 **Улучшить прибыльность** - найти параметры с максимальной доходностью
- 🎯 **Повысить винрейт** - оптимизировать процент прибыльных сделок
- 📉 **Снизить просадку** - минимизировать максимальную потерю капитала
- ⚖️ **Балансировать риск/доходность** - найти оптимальное соотношение

### ⚠️ Важные предупреждения
- **Овerfitting риск** - параметры идеальные на истории могут не работать в будущем
- **Тестируйте на разных периодах** - оптимизация на 2023, тест на 2024
- **Используйте консервативные параметры** - не гонитесь за максимальной прибылью на бэктесте

## Как запустить оптимизацию

### Шаг 1: Откройте раздел "Backtest & Optimization"
Нажмите на заголовок **"▶ BACKTEST & OPTIMIZATION"** чтобы развернуть секцию.

### Шаг 2: Переключитесь на вкладку "Optimization"
Справа от кнопки "Run Backtest" есть кнопка **"Optimization"**.

### Шаг 3: Настройте параметры оптимизации

```
Symbol:       XAUUSD / EURUSD    (инструмент для оптимизации)
Year:         2023 / 2024 / 2025 (период данных)
Method:       Grid Search / Random Search (метод поиска)
Metric:       combined / profit / sharpe / winrate / drawdown (метрика)
Iterations:   50 (только для Random Search - количество попыток)
```

### Шаг 4: Запустите оптимизацию
Нажмите **"▶ Run Optimization"**

### Шаг 5: Дождитесь результатов
- Прогресс показывается в процентах
- Для Grid Search может потребоваться 5-30 минут
- Для Random Search обычно 2-10 минут

## Методы оптимизации

### 🔷 Grid Search (Полный перебор)

**Описание**: Тестирует ВСЕ возможные комбинации параметров.

**Преимущества**:
- ✅ Гарантированно найдет лучшую комбинацию
- ✅ Систематичный подход
- ✅ Не пропустит оптимальные параметры

**Недостатки**:
- ❌ Медленно (может быть тысячи комбинаций)
- ❌ Требует много времени на больших пространствах

**Когда использовать**:
- Когда нужен точный результат
- Для маленьких пространств параметров (2-4 параметра)
- Для финальной оптимизации перед продакшеном

**Пример параметров** (по умолчанию):
```python
{
    'atr_period': [14, 20],           # 2 варианта
    'atr_multiplier': [1.5, 2.0, 2.5], # 3 варианта
    'risk_percent': [0.01, 0.02],      # 2 варианта
    'min_rr': [1.5, 2.0]               # 2 варианта
}
# Всего комбинаций: 2 × 3 × 2 × 2 = 24
```

---

### 🔶 Random Search (Случайный поиск)

**Описание**: Тестирует СЛУЧАЙНУЮ выборку комбинаций из всего пространства.

**Преимущества**:
- ✅ Намного быстрее Grid Search
- ✅ Хорошо находит "около-оптимальные" решения
- ✅ Можно контролировать время (iterations)

**Недостатки**:
- ❌ Не гарантирует нахождение лучшей комбинации
- ❌ Может пропустить оптимум

**Когда использовать**:
- Для быстрой проверки идей
- Для больших пространств параметров (5+ параметров)
- Для первичного исследования

**Настройка iterations**:
- `50` - быстрая проверка (2-5 мин)
- `100` - стандартная оптимизация (5-10 мин)
- `200+` - глубокий поиск (10-30 мин)

## Метрики оптимизации

### 🏆 Combined (Комбинированная) - РЕКОМЕНДУЕТСЯ

**Формула**: `Sharpe × WinRate × (1 - MaxDrawdown/100)`

**Что оптимизирует**: Баланс между прибыльностью, стабильностью и риском.

**Когда использовать**: 
- По умолчанию для всех стратегий
- Когда нужен универсальный подход
- Для продакшен-оптимизации

**Плюсы**: 
- Не даст получить "однобокие" параметры
- Учитывает все важные факторы
- Меньше риск overfitting

---

### 💰 Profit (Прибыль)

**Что оптимизирует**: Максимальную доходность в процентах (ROI).

**Когда использовать**:
- Когда нужна максимальная прибыль
- Для агрессивных стратегий
- Если готовы принять высокие просадки

**⚠️ Осторожно**: Может найти параметры с огромной просадкой!

---

### 📊 Sharpe (Коэффициент Шарпа)

**Что оптимизирует**: Отношение доходности к волатильности.

**Когда использовать**:
- Для стабильных стратегий
- Когда важна предсказуемость
- Для институциональных подходов

**Note**: В текущей версии Sharpe=0 (TODO: добавить расчет)

---

### 🎯 Winrate (Процент прибыльных сделок)

**Что оптимизирует**: Максимальный % выигрышных трейдов.

**Когда использовать**:
- Для психологического комфорта
- Когда нужно много мелких побед
- Для scalping стратегий

**⚠️ Осторожно**: Высокий винрейт ≠ прибыльность! Можно иметь 80% винрейт и терять деньги.

---

### 📉 Drawdown (Просадка)

**Что оптимизирует**: Минимальную максимальную просадку.

**Когда использовать**:
- Для консервативных счетов
- Когда капитал ограничен
- Для соблюдения risk management

**Плюсы**: Защита капитала
**Минусы**: Может найти слишком осторожные параметры с низкой прибылью

## Параметры стратегий

### XAUUSD Strategy (Gold)

#### 📏 ATR Period
- **Диапазон**: 14-30
- **Что делает**: Период расчета Average True Range (волатильность)
- **Влияние**: 
  - Меньше → быстрее реакция на изменения
  - Больше → более сглаженные значения

#### ⚡ ATR Multiplier
- **Диапазон**: 1.5-3.0
- **Что делает**: Множитель для расстояния Stop Loss
- **Влияние**:
  - Меньше → более частые сделки, но больше SL срабатываний
  - Больше → реже сделки, но больше защиты

#### 💵 Risk Percent
- **Диапазон**: 0.01-0.02 (1%-2%)
- **Что делает**: Риск на сделку от баланса
- **Влияние**:
  - Меньше → консервативно, медленный рост
  - Больше → агрессивно, быстрый рост но большие просадки

#### 🎯 Min RR (Risk/Reward)
- **Диапазон**: 1.5-2.5
- **Что делает**: Минимальное соотношение прибыли к риску
- **Влияние**:
  - Меньше → больше сделок
  - Больше → реже сделки, но выше потенциал

#### 📦 Order Block Lookback
- **Диапазон**: 10-20
- **Что делает**: Количество свечей для поиска Order Block
- **Влияние**:
  - Меньше → ищет недавние OB
  - Больше → ищет более значимые OB

#### 🕳️ FVG Min Size
- **Диапазон**: 0.5-1.5
- **Что делает**: Минимальный размер Fair Value Gap
- **Влияние**:
  - Меньше → больше FVG находит
  - Больше → только крупные FVG

#### 📈 Trend EMA Fast/Slow
- **Диапазон**: Fast: 20-50, Slow: 100-200
- **Что делает**: Период быстрой/медленной EMA для тренда
- **Влияние**:
  - Меньше → быстрее реакция
  - Больше → надежнее сигнал

Аналогичные параметры + специфичные для SMC Retracement:

#### 📊 FVG Threshold

### Как читать результаты

#### 1. Score (Оценка)
- **0.8-1.0**: Отличные параметры ⭐⭐⭐
- **0.6-0.8**: Хорошие параметры ⭐⭐
- **0.4-0.6**: Средние параметры ⭐
- **< 0.4**: Слабые параметры ❌

#### 2. Total Return (Доходность)
- **> 30%**: Отлично для года
- **15-30%**: Хорошо
- **5-15%**: Приемлемо
- **< 5%**: Слабо

#### 3. Win Rate (Винрейт)
- **> 60%**: Отлично
- **50-60%**: Хорошо
- **40-50%**: Приемлемо
- **< 40%**: Требует улучшения

#### 4. Max Drawdown (Просадка)
- **< 10%**: Отлично ✅
- **10-20%**: Приемлемо ⚠️
- **20-30%**: Рискованно ⚠️⚠️
- **> 30%**: Опасно ❌

#### 5. Total Trades (Количество сделок)
- **> 50**: Достаточно для статистики ✅
- **20-50**: Нормально ⚠️
- **< 20**: Мало данных ❌

## Рекомендации

### ✅ DO (Рекомендуется)

1. **Оптимизируйте на одном периоде, тестируйте на другом**
   ```
   Оптимизация: 2023 год
   Проверка: 2024 год
   Live: 2025 год
   ```

2. **Используйте Combined метрику по умолчанию**
   - Сбалансированный подход
   - Меньше риск overfitting

3. **Запускайте Grid Search для финальных параметров**
   - После того как Random Search дал примерный диапазон

4. **Проверяйте результаты вручную**
   - Запустите отдельный бэктест с найденными параметрами
   - Убедитесь что результаты повторяются

5. **Документируйте результаты**
   - Сохраняйте конфигурации
   - Записывайте даты оптимизации
   - Отслеживайте результаты на live

### ❌ DON'T (Не рекомендуется)

1. **Не используйте параметры без проверки**
   - Сначала бэктест, потом demo, потом live

2. **Не гонитесь за максимальной прибылью**
   - 100% ROI на бэктесте ≠ 100% на live
   - Консервативные параметры надежнее

3. **Не оптимизируйте на всех данных сразу**
   - Оставляйте период для out-of-sample тестирования

4. **Не меняйте параметры слишком часто**
   - Дайте стратегии время показать себя
   - Минимум 1-2 месяца на одних параметрах

5. **Не игнорируйте просадку**
   - Даже с высокой прибылью, 50% DD = риск слива счета

## FAQ

**Q: Сколько времени занимает оптимизация?**
A: Random Search (100 iter) ≈ 5-10 мин, Grid Search ≈ 15-30 мин

**Q: Можно ли оптимизировать на нескольких годах сразу?**
A: Нет, сейчас только один год за раз. Но можно запустить 3 раза (2023, 2024, 2025) и сравнить.

**Q: Что делать если все результаты плохие?**
A: 
1. Попробуйте другую метрику
2. Расширьте пространство параметров
3. Проверьте данные (возможно плохой период)

**Q: Можно ли добавить свои параметры?**
A: Да, редактируйте `src/backtest/optimizer.py` метод `get_parameter_space()`

**Q: Параметры на 2023 не работают на 2024. Почему?**
A: Overfitting. Попробуйте более консервативные параметры или используйте Combined метрику.

**Q: Как сохранить результаты оптимизации?**
A: Сейчас только копировать вручную из GUI. TODO: добавить сохранение в файл.

## Техническая информация

### Архитектура

```
src/backtest/optimizer.py
  ├── StrategyOptimizer
  │   ├── optimize_grid_search()
  │   ├── optimize_random_search()
  │   └── _run_backtest()
  │
  └── Использует:
      ├── StrategyBacktester (реальный бэктест)
      ├── StrategyXAUUSD / StrategyEURUSD (настоящие стратегии)
      └── DataLoader (загрузка H1 + M15 данных)
```

### Поток выполнения

```
1. GUI → StrategyOptimizer(symbol, start_date, end_date)
2. Optimizer → генерирует комбинации параметров
3. Для каждой комбинации:
   a. Создает стратегию (StrategyXAUUSD/EURUSD)
   b. Применяет параметры к стратегии
   c. Запускает StrategyBacktester
   d. Получает метрики
   e. Вычисляет score
4. Сортирует по score
5. Возвращает ТОП-N результатов
```
