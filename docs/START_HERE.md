# 👋 Привет! Это BAZA Trading Bot

## Что это?

**Автоматический торговый бот для MetaTrader 5 с искусственным интеллектом GPT-4**

Бот анализирует рынок каждые 5 минут, делает скриншоты графиков, читает новости и принимает торговые решения на основе AI.

---

## 🚀 Как начать? (Просто!)

### Шаг 1: Проверь что установлено

Тебе нужны:
- ✅ **Windows 10 или 11**
- ✅ **Python 3.9+** (скачай с https://www.python.org/downloads/)
  - ⚠️ При установке **ОБЯЗАТЕЛЬНО** отметь "Add Python to PATH"
- ✅ **MetaTrader 5** (установи и настрой demo/real счёт)

### Шаг 2: Запусти установку

**Самый простой способ:**
1. Найди файл `install.bat` в папке проекта
2. Двойной клик по нему
3. Жди 2-5 минут пока всё установится

**Или через PowerShell:**
```powershell
.\install.ps1
```

### Шаг 3: Настрой конфигурацию

1. Открой папку `config`
2. Найди файлы `.example` и скопируй их:
   - `mt5.yaml.example` → `mt5.yaml`
   - `telegram.yaml.example` → `telegram.yaml`
3. Открой скопированные файлы и заполни:

**mt5.yaml:**
```yaml
login: 12345678          # Твой логин MT5
password: "password123"  # Твой пароль
server: "Broker-Server"  # Сервер брокера
```

**telegram.yaml:**
```yaml
bot_token: "123:ABC"     # Токен от @BotFather
chat_id: "123456789"     # ID от @userinfobot
```

### Шаг 4: Проверь установку

```powershell
.\check_install.ps1
```

Должно быть всё ✅ зелёное!

### Шаг 5: Запусти бота!

```powershell
.\start_bot.ps1
```

или

```powershell
python main.py
```

## ❗ Если что-то пошло не так

### "Не удается запустить скрипт"

**Решение:**
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Затем запусти `install.ps1` снова.

### "Python не найден"

**Решение:**
1. Скачай Python с https://www.python.org/downloads/
2. **ОБЯЗАТЕЛЬНО** отметь "Add Python to PATH" при установке
3. Перезапусти PowerShell
4. Попробуй ещё раз

### Другие проблемы?

Открой файл `TROUBLESHOOTING.md` - там решения 15+ типичных проблем!

## ⚙️ Где что настраивается?

Все настройки в папке `config/`:

- **trading.yaml** - параметры торговли (риск, лот и т.д.)
- **ai.yaml** - настройки AI (уверенность, интервал анализа)
- **instruments.yaml** - инструменты для торговли
- **portfolio.yaml** - параметры для каждого инструмента
