### 🐛 Исправление загрузки API ключа
Самая частая проблема пользователей — **пустое поле API key при открытии Settings**.

**Было (v1.2.6 и ранее):**

**Стало (v1.2.7):**

### 🧹 Telegram: Автоочистка старых команд
Пользователи видели **старые команды** в боте (из предыдущих версий).

**Было:**
```

/start
/status
/launch_bot
/stop_bot
...ещё 10 старых команд
```

**Стало:**
- При старте бота автоматически удаляются ВСЕ старые команды
- Устанавливается только `/start`
- Всё остальное работает через кнопки меню
- Чистое и понятное меню для всех пользователей ✅

### 📅 Умное отображение даты в истории
Раньше непонятно было **когда создан сигнал** — сегодня или неделю назад.

**Было (v1.2.6):**
```
🎯 03:22:37  XAUUSD Triggered @ 4603.70
✨ 09:15:36  XAUUSD Created
✨ 19:26:56  XAUUSD Created
```
*Непонятно какие из них сегодня, а какие вчера*

**Стало (v1.2.7):**
```
🎯 03:22:37     XAUUSD Triggered @ 4603.70  ← сегодня (только время)
✨ 09:15:36     XAUUSD Created              ← сегодня
🎯 18.01 09:36  XAUUSD Triggered @ 4609.15  ← вчера (дата + время)
✨ 17.01 19:26  XAUUSD Created              ← позавчера
```

**Логика отображения:**
- ✅ Сигнал сегодня → показываем только время `HH:MM:SS`
- ✅ Сигнал вчера/старше → показываем дату + время `DD.MM HH:MM`

Теперь сразу видно насколько свежие сигналы! 🎯

## ⚙️ Конфигурация

### Настройка OpenAI API ключа
1. Открыть Settings (⚙️)
2. Перейти во вкладку **GPT API**
3. Вставить ключ (получить на https://platform.openai.com/api-keys)
4. Нажать **Save & Apply**

Теперь при повторном открытии ключ будет загружен и отображён! ✅

### Настройка Telegram бота
1. Открыть Settings → **Telegram**
2. Включить **Enable Telegram notifications**
3. Вставить **Bot Token** (от @BotFather)
4. Вставить **Chat ID** (ваш ID в Telegram)
5. Нажать **Apply & Restart**

При первом старте бота старые команды автоматически удалятся! 🧹

## 📊 Технические детали

### Умное отображение даты

**Код в app.py (метод `_create_history_item`):**
```python
# Умное отображение: если сегодня - только время, иначе дата + время
now = datetime.now()
if dt.date() == now.date():
    # Сегодня - показываем только время
    time_display = dt.strftime("%H:%M:%S")
else:
    # Вчера или старше - показываем дату + время
    time_display = dt.strftime("%d.%m %H:%M")
```

### Загрузка API ключа

**Код в settings_dialog.py:**
```python
# Загрузить существующий API ключ из .env
try:
    import os
    from dotenv import load_dotenv
    env_path = Path('.env')
    if env_path.exists():
        load_dotenv(env_path)
        existing_key = os.getenv('OPENAI_API_KEY', '')
        if existing_key:
            self.gpt_api_key.insert(0, existing_key)
except Exception as e:
    logger.warning(f"[SETTINGS] Failed to load API key: {e}")
```

### Очистка Telegram команд

**Код в telegram_bot.py:**
```python
async def _setup_bot_commands(self):
    """Настройка команд бота (удаление старых + установка новых)"""
    try:
        # Удалить все старые команды
        await self.application.bot.delete_my_commands()
        logger.info("✅ Старые команды удалены")
        
        # Установить только /start (остальное через кнопки)
        from telegram import BotCommand
        commands = [
            BotCommand("start", "🤖 Запустить бота и показать меню")
        ]
        await self.application.bot.set_my_commands(commands)
        logger.info(f"✅ Установлены новые команды: {[cmd.command for cmd in commands]}")
    except Exception as e:
        logger.error(f"❌ Ошибка настройки команд: {e}")
```

## 🆘 Поддержка

### Частые вопросы

**Q: API ключ все еще пустой в Settings?**
A: 
1. Убедитесь что используете v1.2.7 (проверьте в заголовке окна)
2. Проверьте что файл `.env` существует и содержит `OPENAI_API_KEY=sk-...`
3. Перезапустите бота

**Q: В Telegram боте остались старые команды?**
A:
1. Полностью остановите бота
2. Запустите заново — команды очистятся автоматически
3. Откройте бота в Telegram и напишите `/start`
4. Должно быть только меню с кнопками

**Q: Как понять когда был создан сигнал?**
A: Теперь это видно сразу:
- Только время (09:15:36) — сегодня
- Дата + время (18.01 09:15) — вчера или старше

**Q: Можно ли изменить формат даты?**
A: Формат фиксирован для единообразия. Но если нужно изменить, измените в `src/gui/app.py` метод `_create_history_item`.

### Решение проблем

**Проблема:** API ключ не загружается
```bash
# Проверка .env файла
1. Откройте папку с ботом
2. Найдите файл .env (может быть скрыт)
3. Откройте в текстовом редакторе
4. Должна быть строка: OPENAI_API_KEY=sk-ваш_ключ
```

**Проблема:** Старые команды не удаляются
```bash
# Полная переустановка команд
1. Остановите бота
2. Откройте BotFather в Telegram
3. Отправьте /mybots → выберите вашего бота → Edit Bot → Edit Commands
4. Удалите все команды вручную
5. Запустите бота — новые команды установятся
```
